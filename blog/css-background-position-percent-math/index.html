Calculate Background Position from the Remaining Space

Understand percentage background positioning with a worked width example. Recalculate after cover scaling and distinguish alignment from a fixed pixel offset.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Work through a fixed-size example
  2. Recalculate when the image grows
  3. Inspect the right box and syntax

A percentage background position aligns a point on the image with the same percentage point in the positioning area. It is not simply that percentage of the container width measured from the left. The image’s rendered size is part of the calculation.

Work through a fixed-size example

.position-sample {
  width: 300px;
  height: 160px;
  background-image: url("/images/sample-mark.webp");
  background-size: 100px 100px;
  background-repeat: no-repeat;
  background-position: 25% 50%;
}

In a 300px-wide positioning area with a 100px-wide rendered background, the available horizontal difference is 200px. At 25%, the left offset is 50px: (300 − 100) × 0.25. Vertically, the 160px area and 100px image leave 60px, so 50% gives 30px.

Reference: MDN percentage background positioning.

Recalculate when the image grows

If the image becomes wider than the area, the difference becomes negative. With a 400px image in a 300px area, 25% produces a −25px offset. This explains why changing a percentage can appear to move a cover background in the opposite direction from an intuitive container-offset model.

Cover and contain first determine the rendered image size from its proportions and the positioning area. Use that resulting size in the reasoning. If image and area widths are equal, the horizontal difference is zero and changing the horizontal percentage has no visible effect.

Inspect the right box and syntax

  • Confirm the background positioning area selected by background-origin.
  • Temporarily use explicit background dimensions to isolate the math.
  • Compare 0%, 50% and 100% before choosing a focal position.
  • Review each image layer separately when values are listed.

Edge-offset syntax such as right 1rem expresses a different positioning instruction; do not silently interpret it as the two-percentage example above. Keep the calculation and intended focal content in the handoff. Use background fitting when the crop changes across viewport shapes, and origin and clipping when padding changes the area you meant to measure.
