Keep Fallback Text Legible with font-size-adjust

Evaluate a fallback font’s apparent size with font-size-adjust. Choose a deliberate metric, test wrapping and distinguish it from changing the declared font size.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Build a controlled fallback specimen
  2. Compare the same paragraph twice
  3. Keep the metric adjustment separate from other repairs

Two fonts at the same CSS font size can have noticeably different lowercase heights. font-size-adjust can help maintain an intended apparent text size when a fallback face is used. It does not make two typefaces identical, and it should be evaluated with the real font stack.

Build a controlled fallback specimen

.reading-sample {
  font-family: "Project Sans", Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
  font-size-adjust: .5;
}

Project Sans is a placeholder for your actual loaded font. The .5 value is an illustrative target ratio, not a measured recommendation for your brand. The ordinary numeric form uses the lowercase x-height metric relative to font size. Measure or evaluate the chosen typeface before selecting a production value.

Reference: MDN: font-size-adjust.

Compare the same paragraph twice

Create a short specimen containing lowercase letters, capitals, digits and punctuation. Use the same container width in both views. First inspect the intended web font, then deliberately select the fallback in DevTools. Record apparent lowercase size, line count and the position of the next component.

Test with adjustment enabled and disabled. Prefer the result that keeps the fallback readable without creating cramped lines or surprising wraps. The acceptance decision should include several paragraphs, not only a large “Aa” specimen that hides ordinary reading problems.

Keep the metric adjustment separate from other repairs

  • Verify the font request and the rendered face before tuning metrics.
  • Check a narrow card and the main reading column.
  • Review punctuation, accents and supported scripts.
  • Confirm enlarged text has enough line and component space.

If the chosen font never loads, fix that delivery problem independently. If a button has a fixed height, review the component constraint before attributing clipped text to the adjustment. Keep a small before-and-after specimen in the handoff, with the font names, declared size and chosen ratio. Report observed wrapping changes honestly; this property alone does not establish that layout shift has been eliminated.
