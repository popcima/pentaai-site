Calculate the Repeat Period of a CSS Stripe Pattern

Read the first and last gradient stops to calculate the repeat period, compare hard transitions, and keep decorative stripes separate from meaningful status.

By Penta AIPublished 24 November 20261 min read

In this guide

  1. Start with two equal horizontal intervals
  2. Separate gradient distance from screen-axis distance
  3. Review the pattern at the actual reading size

A repeating linear gradient repeats the interval between its first and last color stops along the gradient line. That interval is the pattern’s period. Confusing a stripe’s width with the complete period makes a background look denser or looser than the specification.

Start with two equal horizontal intervals

.stripe-sample {
  min-height: 5rem;
  background: repeating-linear-gradient(
    90deg,
    #e4ecf7 0 8px,
    #c8d9ee 8px 16px
  );
}

This specimen has an 8px interval in each color and a 16px period. Adjacent stops meet at 8px to create a hard boundary. At 90 degrees, the gradient changes along the horizontal axis, so the resulting stripes appear vertical.

Reference: MDN CSS repeating linear gradient period.

Separate gradient distance from screen-axis distance

Change the angle while keeping the stops fixed. The distances still belong to the gradient line; the apparent spacing along the page’s horizontal edge changes with the angle. A diagonal pattern cannot be specified reliably by measuring only a horizontal screenshot slice.

A blended interval appears when adjacent color boundaries do not meet as hard stops. Inspect both colors and their positions before blaming image scaling. Repeating gradients are generated images, so their sharpness and apparent density can also vary at fractional pixel positions and browser zoom levels.

Review the pattern at the actual reading size

Compare the original pattern with doubled stop distances and with a different angle. Test narrow containers and enlarged text. Dense stripes behind copy can interfere with reading even when the individual colors seem subtle.

Use the pattern as decoration or supplement it with a visible label when it represents a state. Do not make “striped” the only way to recognize a disabled, selected or loading area. A reader who cannot see the background must still understand the component.

Inspect gradient angles and boundaries. Distinguish gradient repetition from image tiling.
