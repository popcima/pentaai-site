Number Section Headings with CSS Counters

Scope a CSS counter to one article and increment it deliberately. Test nested components and hidden headings, and keep essential numbering in semantic content.

By Penta AIPublished 16 November 20262 min read

In this guide

  1. Scope the counter to the intended article
  2. Review structural changes, not just the first render
  3. Check alternate ways of reading the document

CSS counters can generate section numbers from document structure. Use a scoped counter when numbering is a visual aid that should follow the sections automatically. If a number is essential to navigation, cross-references or an exported document, represent that meaning in the content model rather than relying only on generated CSS text.

Scope the counter to the intended article

.numbered-guide { counter-reset: section; }
.numbered-guide > section { counter-increment: section; }
.numbered-guide > section > h2::before {
  content: counter(section) ". ";
  color: #174fa0;
}

This example assumes direct child sections, each with a direct h2. The narrow selectors keep an unrelated nested component from incrementing the same sequence. Counter-reset creates the starting counter scope, counter-increment advances it, and counter() inserts the displayed value.

Reference: MDN CSS counters guide.

Review structural changes, not just the first render

Add, remove and reorder a section in a local fixture. Then insert a nested example containing another heading. A broad selector such as every h2 inside the article may accidentally count that example as a top-level section. The CSS should follow the intended information structure, not merely all tags of a certain size.

Hidden and conditionally rendered sections also need testing. An element removed from rendering with display: none does not behave like a visible numbered section for counters. Decide whether the numbering should follow visible sections or stable content identifiers before choosing the implementation.

Do not hard-code prose such as “see section 4” when the visible sequence is dynamically generated and can change. Use descriptive links to stable section IDs. If a legal, procedural or reference number must remain stable, store it explicitly and keep it consistent across HTML and exports.

Check alternate ways of reading the document

  • Disable the counter styling and confirm the headings still make sense.
  • Inspect screen-reader output for generated prefixes and unwanted repetition.
  • Copy text and review a print or export version.
  • Test multiple article instances on the same page.
  • Confirm heading levels remain semantic rather than chosen for their numbering.

For ordered steps, begin with a real ordered list and style its markers when appropriate. A heading counter does not create list semantics. Use the heading audit to establish the structure first, then add numbering as an intentional presentation layer.
