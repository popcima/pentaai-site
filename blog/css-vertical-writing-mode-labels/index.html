Lay Out Vertical Text with writing-mode and text-orientation

Use writing-mode for vertical text flow and text-orientation for glyph direction. Review logical sizing, language and reading order before rotating labels.

By Penta AIPublished 18 November 20261 min read

In this guide

  1. Compare flow before changing individual glyphs
  2. Inspect logical dimensions and language together
  3. Review the component as an interaction

Writing-mode changes how text lines flow through a box. Text-orientation controls the glyph orientation within vertical text. They solve a different problem from rotating an already laid-out horizontal box with transform, which leaves its original layout space behind.

Compare flow before changing individual glyphs

.rail-label {
  writing-mode: vertical-rl;
  text-orientation: mixed;
  padding-block: .75rem;
  padding-inline: 1rem;
}

Use a short real label in a component rail, then test a longer label and mixed-script text. Vertical-rl stacks lines from right to left; vertical-lr changes that progression. Mixed allows character orientation appropriate to the script, while upright requests upright characters. Do not assume those choices produce equally readable English labels.

Reference: MDN writing-mode.

Reference: MDN text-orientation.

Inspect logical dimensions and language together

In vertical writing, the inline dimension runs along the vertical text flow. A max-inline-size therefore constrains a different physical direction than it does in horizontal English text. Use logical properties deliberately and inspect the computed box instead of carrying over a width assumption from a horizontal specimen.

Language metadata remains important for the content itself. Vertical layout does not tell the browser which language the words use, and it is not a reason to alter the document’s semantic order. Keep the visible label in real text so it remains selectable and available to assistive technology.

Review the component as an interaction

  • Tab through nearby controls in document order.
  • Increase text size and test the longest label.
  • Review a narrow viewport where the rail may need a horizontal fallback.
  • Check mixed Latin and non-Latin characters in the actual font.

If the design merely asks for a short decorative sideways word, compare the layout consequences of rotation before choosing it. For functional navigation, prioritize legibility and predictable controls over the shape of the rail. The logical-properties guide helps record which dimensions follow text flow and which intentionally stay physical.
