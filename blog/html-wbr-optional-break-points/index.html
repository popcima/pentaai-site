Add Optional Break Points to a Long Label with wbr

Use wbr for chosen line-break opportunities, distinguish it from br and soft hyphens, and preserve the actual label text when readers copy it.

By Penta AIPublished 23 November 20261 min read

In this guide

  1. Keep the label’s characters intact
  2. Choose the appropriate breaking mechanism
  3. Review both wide and very narrow boxes

Wbr marks a place where a line may break if needed. It does not force a new line like br and does not add a visible hyphen. Use it when a long machine-oriented label has meaningful boundaries that automatic wrapping does not express well.

Keep the label’s characters intact

<p class="asset-name">component<wbr>Preview<wbr>Desktop<wbr>2026.svg</p>
<style>
.asset-name { max-inline-size: 12rem; font-family: monospace; }
</style>

The source word can wrap between the chosen segments when the box becomes narrow. In a wide box, the optional opportunities need not produce breaks. There is no inserted space or hyphen between Preview and Desktop; wbr is a structural opportunity rather than an extra filename character.

Reference: MDN HTML wbr optional line breaks.

Choose the appropriate breaking mechanism

A br expresses an intentional line break, which is stronger than a responsive opportunity. A soft hyphen can show a hyphen when breaking a word. Overflow-wrap supplies a broader emergency policy for arbitrary content, while wbr lets an author identify preferred boundaries in a known string.

Do not insert hundreds of opportunities into ordinary prose to compensate for a poor text measure. For user-generated identifiers, decide which delimiters are meaningful and preserve the original value used for links, downloads and copying.

Review both wide and very narrow boxes

Resize the specimen until each boundary is exercised, then copy the rendered label into a plain-text editor and compare it with the real filename. Check screen-reader pronunciation if the label is an important control name; visual grouping is not a guaranteed spoken pause.

A segment can still be wider than the available box. Decide whether that case should allow emergency wrapping, local scrolling or a separately accessible full value. Optional breaks solve a placement question, not every overflow or truncation requirement.

Choose an emergency wrapping policy. Preserve access to truncated values.
