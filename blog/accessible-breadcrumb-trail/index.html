Build a Breadcrumb Trail That Explains Page Location

Use a labeled navigation region and ordered links for page ancestry. Mark the current page, keep separators decorative and let long breadcrumb labels wrap.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Represent ancestry with ordinary navigation
  2. Allow the trail to fit real content
  3. Review the hierarchy and interaction

A breadcrumb describes the current page’s place in a hierarchy, not the user’s recent browsing history. Use links to meaningful parent locations and a clearly identified current item. Keep the trail short enough to help orientation without replacing the page heading.

Represent ancestry with ordinary navigation

<nav aria-label="Breadcrumb">
  <ol class="breadcrumbs">
    <li><a href="/">Home</a></li>
    <li><span aria-hidden="true">/</span> <a href="/guides/">Guides</a></li>
    <li><span aria-hidden="true">/</span> <span aria-current="page">Color review</span></li>
  </ol>
</nav>

The routes and current title are an illustrative hierarchy. Replace them with actual parent destinations. A current-page link should carry aria-current page; for a non-link current item, the APG makes that attribute optional. The example includes it explicitly and hides the decorative separators from accessibility exposure.

Reference: W3C breadcrumb pattern.

Allow the trail to fit real content

.breadcrumbs {
  display: flex;
  flex-wrap: wrap;
  gap: .5rem;
  padding: 0;
  list-style: none;
}
.breadcrumbs li { overflow-wrap: anywhere; }

Test a long current title and long parent labels, not only Home and Guides. Keep each separator with its following item so a wrap does not leave a misleading isolated slash. Do not hide necessary ancestor links merely to preserve one-line symmetry.

If the page has several navigation regions, distinguish their accessible labels. The breadcrumb remains a set of ordinary links; it does not need menu roles or custom arrow-key behavior. Preserve the native Tab and link activation experience.

Review the hierarchy and interaction

  • Open each parent link and confirm its destination.
  • Check that the current item matches the visible page heading.
  • Inspect the navigation name and current-page state.
  • Test wrapping, enlarged text and narrow screens.

Use the landmark guide for multiple navigation regions and current-page state guidance for repeated navigation sets. Record the actual hierarchy in the content model so breadcrumbs do not become manually maintained strings that drift from the site’s structure.
