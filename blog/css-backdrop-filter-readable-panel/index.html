Blur Behind a Panel Without Blurring Its Text

Separate filter from backdrop-filter, keep a readable solid fallback, and inspect the surfaces behind a translucent panel before approving its contrast.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Keep a usable surface before adding blur
  2. Inspect the backdrop boundary and compositing
  3. Review changing content behind the surface

Filter changes the rendered element, including its contents. Backdrop-filter changes pixels behind the element within its backdrop boundary. For a frosted panel with sharp text, apply the backdrop effect to the panel and give it a partially transparent surface.

Keep a usable surface before adding blur

.review-panel {
  color: #13261c;
  background: #eff7f2;
  padding: 1.5rem;
  border: 1px solid #bbcfc2;
}
@supports (backdrop-filter: blur(8px)) {
  .review-panel {
    background: rgb(239 247 242 / .88);
    backdrop-filter: blur(8px);
  }
}

Place the panel over a detailed decorative background so the effect can be compared. The initial solid surface is the fallback. The supported enhancement makes some background visible without applying blur to the text. These colors and opacity are specimen values to assess with the actual content behind your panel.

Reference: MDN backdrop-filter.

Inspect the backdrop boundary and compositing

An opaque panel background can conceal the effect even when the declaration is active. Ancestor effects can establish a backdrop boundary, limiting which pixels are filtered. Inspect the relevant ancestor chain before increasing blur to compensate for a missing visual change.

Do not lower the whole panel’s opacity to create transparency: that also fades its text and controls. A background alpha value and element opacity have different consequences. A blurred photograph can still contain bright and dark regions that affect readability.

Review changing content behind the surface

Move the panel over both the lightest and darkest expected background regions, then disable backdrop-filter. Read the labels, focus outlines and secondary text in each case. Scroll a representative page and inspect rendering performance if the effect feels slow. Keep a solid surface when the effect makes the interface less dependable.

Compare alpha backgrounds and opacity, and use the state-by-state contrast review with the final composited colors.
