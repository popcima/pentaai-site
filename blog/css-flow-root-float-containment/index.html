Contain a Floated Image with display: flow-root

Keep a floated illustration inside its section without using overflow as a layout fix. Compare float containment, clipping and deliberate text wrapping.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Reproduce the short-text case
  2. Separate containment from clipping
  3. Confirm that a float is still the right layout

A section containing a floated image can appear shorter than the image when its normal-flow text ends early. Use display: flow-root on the section to establish a block formatting context that contains its floats, while preserving text wrapping around the image.

Reproduce the short-text case

.editorial-note {
  display: flow-root;
  padding: 1rem;
  border: 1px solid #ccd5ce;
}
.editorial-note img {
  float: inline-start;
  width: 8rem;
  height: auto;
  margin-inline-end: 1rem;
  margin-block-end: .5rem;
}

Place an image and one short paragraph inside the section. Temporarily remove flow-root and inspect whether the border encloses the float. Then restore it and compare with a much longer paragraph. The container should behave sensibly in both fixtures, rather than relying on enough text to push its bottom edge down.

Reference: MDN block formatting contexts.

Separate containment from clipping

Overflow rules can create a block formatting context too, but they also carry scrolling or clipping consequences. Using overflow hidden merely to contain a float may cut off a shadow, a focus indicator or an overlapping decoration. Flow-root makes the containment purpose explicit without asking for clipping.

This does not make arbitrary absolutely positioned children contribute to the section’s height. It addresses float behavior within the new formatting context. It can also affect margin collapsing at the boundary, so review the first and last text margins rather than assuming every spacing relationship stays identical.

Confirm that a float is still the right layout

Floats are useful when prose should wrap beside an illustration and later continue beneath it. If the requirement is a rigid image-and-text pair with independent columns, grid or flexbox is usually easier to specify. Choose based on the flow of content, not on which property first makes a screenshot resemble a mockup.

  • Test a short paragraph and several long paragraphs.
  • Check narrow widths where the illustration dominates the line.
  • Inspect outlines and shadows near the section’s edges.
  • Check the margin boundary after enabling flow-root.

For overflow changes, review hidden versus clip separately. The final handoff should say whether the illustration floats within prose, sits in a separate track or intentionally overlaps the section; these are different layout contracts.
