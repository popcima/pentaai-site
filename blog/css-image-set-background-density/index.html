Use image-set() for Sharp CSS Backgrounds

Offer standard and high-density CSS background images with image-set(). Keep a fallback, verify asset dimensions and inspect the browser’s selected request.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Prepare two versions of the same artwork
  2. Keep resolution and composition separate
  3. Verify selection and visual size

Use image-set() to offer multiple resolutions of a decorative CSS background. It gives the browser candidates rather than forcing the largest file onto every device. When the image communicates information that needs alternative text, use appropriate HTML image markup instead of moving that content into a background.

Prepare two versions of the same artwork

.texture-panel {
  background-image: url("/images/paper-1x.webp");
  background-image: image-set(
    url("/images/paper-1x.webp") 1x,
    url("/images/paper-2x.webp") 2x
  );
  background-size: 320px 200px;
  background-repeat: repeat;
}

For this illustrative repeating texture, prepare a 320 by 200 pixel base asset and a 640 by 400 pixel high-density asset with the same composition. Both represent the same 320 by 200 CSS-pixel tile. Replace the paths with actual project files before using the example.

Reference: MDN: image-set().

Keep resolution and composition separate

A 2x candidate should provide more image detail for the same intended appearance. If it also changes the crop or moves a decorative mark, switching candidates will change the design. Use a deliberate art-direction strategy when the composition itself needs to change at a breakpoint.

The earlier background-image declaration provides a plain-image fallback. Supporting browsers can choose an image-set candidate based on device and environment. Do not assume that a particular device pixel ratio always proves one exact file must be selected; inspect the actual network request.

Verify selection and visual size

  • Check that both files return successfully and have the intended pixel dimensions.
  • Inspect the requested background file in the Network panel.
  • Compare the tile’s visible CSS size across density settings.
  • Look for seams and compression artifacts in the high-density version.

Use a fresh load when evaluating selection and account for caching. A previously loaded candidate can make a quick experiment misleading. Record the viewport, density setting and requested file in the review evidence instead of judging only from a screenshot.

If the design uses background-size: cover, also test the crop in the actual element proportions. Extra resolution cannot restore content that cover crops away. For large decorative photography, review file weight as well as sharpness; the high-density candidate should earn its transfer cost at the size people actually see.

Document the logical display size, each source’s pixel dimensions and the asset’s decorative role. That prevents a later export from silently changing the scale of the background pattern.
