Keep Useful Text Selectable with CSS user-select

Review where text selection helps the task. Use user-select sparingly, support partial copying and avoid treating selection blocking as content protection.

By Penta AIPublished 15 November 20262 min read

In this guide

  1. Choose between partial and whole-value selection
  2. Inspect ancestors when selection fails
  3. Test realistic copying tasks

Keep article text, reference codes and error messages selectable unless there is a clear interaction reason to change that behavior. User-select controls selection behavior; it does not protect content from copying, scraping or viewing in the page source.

Choose between partial and whole-value selection

.reference-code { user-select: all; }
.review-notes { user-select: text; }

All can be useful for a short reference code that users normally copy in full. Text allows ordinary partial selection, which is valuable for prose and code examples where readers may want only one line. Test both with the actual content before applying one rule to every snippet.

Reference: MDN user-select reference.

Avoid a global body rule that disables selection. It can prevent users from copying an error into a support request, translating a paragraph or selecting the exact value they need. A polished interface should still support those ordinary reading tasks.

Inspect ancestors when selection fails

Search the selected element and its ancestors for user-select declarations, including prefixed declarations in older stylesheets. Browser behavior around inheritance has differed, so inspect the result in your supported engines rather than assuming the nearest rule fully explains it.

Also check overlays and pointer handling. A transparent layer may intercept the drag that would begin selection even when the text’s selection CSS is correct. Temporarily disable the suspected layer in a local reproduction to separate hit testing from text-selection behavior.

A copy button can complement selection, but it needs its own implementation, failure handling and visible result. Do not remove manual copying because a clipboard API call works in one browser. Keep the displayed content as the source of truth and avoid silently copying a different value.

Test realistic copying tasks

  • Select one word, one line and the complete value.
  • Copy multiline text and inspect its whitespace in a plain-text editor.
  • Try touch selection handles and keyboard selection.
  • Check that nearby controls remain operable without an overlay intercepting input.
  • Verify copy-button failure still leaves a usable manual path.

For a code sample, decide whether line numbers and decorative prefixes belong in copied text. Keep them out of the content where possible instead of relying on brittle selection tricks. Use the whitespace guide when preserving meaningful line breaks is part of the copying task.
