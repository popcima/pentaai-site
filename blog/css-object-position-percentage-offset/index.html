Calculate an Image Crop Offset from object-position

Work through object-position percentage math using a known image and box, identify the axis that can move, and verify the crop at responsive sizes.

By Penta AIPublished 23 November 20261 min read

In this guide

  1. Use a specimen with known geometry
  2. Distinguish a position value from a focal coordinate
  3. Recalculate after changing the box shape

Object-position percentages align a point in the fitted image with the same percentage point in its box. They are not a simple instruction to move the image that percentage of its own width. Calculate the remaining space after object-fit has scaled the content.

Use a specimen with known geometry

.crop-demo {
  display: block;
  width: 200px;
  height: 200px;
  object-fit: cover;
  object-position: 25% 50%;
}

Use a 400-by-200 image with labeled left and right edges. Cover keeps this image at 400 by 200 inside the 200px square. The horizontal remaining space is 200 minus 400, or -200px. Multiplying by 25% gives a -50px offset: the leftmost 50px of image content is cropped. Vertical remaining space is zero, so changing the second percentage has no visible effect in this specimen.

Reference: MDN object-position percentage calculation.

Distinguish a position value from a focal coordinate

A recorded subject coordinate is not automatically the object-position value that centers that subject in every crop. The fitted dimensions and box proportions also matter. Compare the intended visible region after scaling before copying a number from an image editor into CSS.

At 0% the left edges align; at 100% the right edges align. At 50%, equal excess is cropped on both sides. These comparisons make it easier to detect a reversed assumption about which direction a larger percentage moves the visible window.

Recalculate after changing the box shape

Change the square to a wide rectangle, then to a portrait box. Measure the fitted dimensions again; the overflowing axis may change. Keep the same source while testing positioning so a responsive source swap does not confuse the result.

Use a separately composed image if the required subject cannot survive the crop. Positioning does not recover content outside the source or reduce the downloaded file size.

Choose the image fitting policy. Verify the selected source and natural dimensions.
