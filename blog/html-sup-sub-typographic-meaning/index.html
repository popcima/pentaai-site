Use Superscripts and Subscripts for Meaningful Notation

Mark up exponents and chemical subscripts with HTML while keeping line spacing readable. Avoid using semantic notation elements for decorative badges.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Start with semantic notation
  2. Review line metrics before applying a reset
  3. Use a richer representation for richer content

Use sup and sub when raised or lowered notation belongs to the content, such as a simple exponent or chemical formula. Do not choose them merely because a promotional badge needs to sit higher beside a heading; decorative placement should be handled with CSS.

Start with semantic notation

<p>The square has an area of 25 m<sup>2</sup>.</p>
<p>The label describes H<sub>2</sub>O.</p>

Read the surrounding sentence as well as the small characters. The superscript 2 describes a square unit; the subscript 2 contributes to the formula. Keep ordinary text intact and let the HTML express that relationship rather than embedding a picture of the notation.

Reference: MDN superscript element.

Reference: MDN subscript element.

Review line metrics before applying a reset

Superscripts and subscripts can affect the line box. Compare a paragraph with notation against one without it using the actual typeface, font size and line height. A cramped line can collide with a neighboring line even if the characters look well aligned in an isolated word.

If the design requires a compact treatment, evaluate it locally instead of applying a global line-height zero rule to every sup and sub. A zero line height can keep notation from expanding the line box while leaving the painted glyphs able to overlap adjacent content. Test high and low glyphs, consecutive lines and enlarged text before accepting that tradeoff.

Use a richer representation for richer content

Simple HTML notation is not a complete mathematical typesetting system. For structured equations, consider MathML and review the accessibility of the actual output. A footnote marker also needs a link and a usable return path when navigation is intended; a raised digit alone does not provide either interaction.

  • Copy the notation and inspect the resulting plain text.
  • Read the sentence with the screen readers you support.
  • Review narrow paragraphs and increased text spacing.
  • Check that small glyphs remain legible rather than shrinking them to preserve a rigid line.

Use the line-height guide to understand inherited spacing and the inline alignment guide for decorative icon placement. Separating meaning from positioning makes both the content and its styling easier to maintain.
