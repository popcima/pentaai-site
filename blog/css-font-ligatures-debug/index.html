Inspect Ligatures Without Changing the Underlying Text

Diagnose joined glyphs with font-variant-ligatures and a controlled specimen. Keep characters intact while checking font features, fallback and readability.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Compare the same text with one feature changed
  2. Inspect the right category of feature
  3. Preserve the content contract

A ligature can render a sequence of characters as a combined glyph. If two letters look joined, inspect the font’s features before inserting spaces or changing the source text. Glyph substitution and the characters people copy are different layers of the typography.

Compare the same text with one feature changed

.sample {
  font-family: "Your Text Font", serif;
  font-size: 2rem;
  letter-spacing: normal;
}
.sample--common { font-variant-ligatures: common-ligatures; }
.sample--without { font-variant-ligatures: no-common-ligatures; }

Use a verified loaded font and a phrase containing candidate pairs such as “office file.” Not every font includes the same substitutions, so no visible change is a valid observation. Compare the same characters, weight and width; changing the text between samples makes it impossible to isolate the feature.

Reference: MDN font-variant-ligatures.

Inspect the right category of feature

Common, discretionary and historical ligatures are different feature categories. Contextual alternates are related but separately controllable. The broad value none disables the feature categories covered by this property; no-common-ligatures targets the common ligature category. Choose the narrow control that expresses the design requirement.

Check low-level font-feature-settings rules and inherited typography styles if the result differs from the local specimen. Confirm the rendered font too: a fallback can have entirely different glyphs. A tighter pair without a changed shape may be kerning rather than a ligature, so compare the outlines as well as the space between them.

Preserve the content contract

  • Copy and paste the sample into a plain text field.
  • Search for the original word in the page.
  • Review long reading passages rather than isolated pairs only.
  • Test any code font separately using real operators and identifiers.

For code, disabling optional substitutions can make individual characters easier to inspect, but it does not change what the code contains. For connected scripts, avoid indiscriminately disabling typographic behavior just to resemble a Latin specimen. Test the actual language and font rather than treating every join as a defect.

Record the requested feature setting alongside the font source. Use the kerning comparison when spacing is the issue and tracking guidance when the entire run is too loose or tight. Do not use invisible characters or extra spaces as a visual repair.
