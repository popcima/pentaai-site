Responsive Images: How srcset and sizes Work Together

Serve suitable image resolutions with srcset and sizes. Match the declared image slot to your layout, reserve space and verify the selected resource in Chrome.

By Penta AIPublished 26 October 20262 min read

In this guide

  1. Match a full-width article image
  2. Account for screen density
  3. Reserve the image’s space
  4. Verify the browser’s choice

Use srcset to offer image candidates and sizes to describe the rendered slot when those candidates use width descriptors. The browser chooses a resource using that information and its environment. CSS still determines the actual layout; an inaccurate sizes value can lead to an unnecessarily large or insufficiently detailed download.

Begin with one component and one source image. Create several resized versions with the same composition, and record each file’s actual pixel width. Do not label a 640px image as 1200w simply because you want the browser to treat it as a larger option.

Match a full-width article image

<img
  src="/images/studio-1200.webp"
  srcset="/images/studio-400.webp 400w,
          /images/studio-800.webp 800w,
          /images/studio-1200.webp 1200w"
  sizes="(max-width: 799px) calc(100vw - 32px), 768px"
  width="1200" height="675"
  alt="A worktable with drawing tools beside a window">

This example assumes 16px page padding on each side below 800px and a 768px image slot above that width. The CSS must implement those assumptions. MDN’s responsive images guide explains width descriptors, density descriptors and how sizes conditions are evaluated.

.article-media {
  width: calc(100% - 32px);
  max-width: 768px;
  margin-inline: auto;
}
.article-media img { display: block; width: 100%; height: auto; }

Place the image inside this wrapper for the example layout. In a real site, the surrounding article container may already provide padding and a maximum width. Adapt the sizes expression to that container instead of adding a second wrapper that changes the intended design.

Account for screen density

Rendered slotIllustrative densityApproximate resource width
384 CSS px1x384 pixels
384 CSS px2x768 pixels
768 CSS px1x768 pixels
768 CSS px2x1536 pixels

The table illustrates resolution needs, not a promise that a particular file is always selected. With the supplied candidates, the last case has no 1536px option. Decide whether a larger export is worthwhile for your artwork, audience and delivery budget after examining the visual result.

Reserve the image’s space

Supply accurate intrinsic dimensions and preserve the intended ratio in CSS. Reserving space helps prevent surrounding content from jumping when an image loads. Google’s layout-shift guidance describes missing image dimensions as one common source of instability.

For a cropped thumbnail, the destination ratio may intentionally differ from the source ratio. Treat that as a separate presentation decision and specify it consistently. The object-fit guide covers how to fill or contain an image within that box.

Verify the browser’s choice

Reload at a representative viewport with DevTools open, inspect the image request and compare its width with the rendered slot. Check another viewport and a higher-density device or emulation setting. Browsers may reuse a previously fetched larger candidate, so shrinking a warm page is not a reliable proof that the smaller candidate is wrong.

Use picture-based art direction when a different composition is required, rather than asking resolution candidates to serve incompatible crops. Finish by recording the component’s slot assumptions, candidate widths and actual loading check. That record makes later layout changes easier to reconcile with the image markup.
