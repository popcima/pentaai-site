Inspect CSS Gradient Angles and Color Stops

Read a linear gradient as a direction and a series of stops. Recreate smooth and hard transitions, then check the result at the component’s actual size.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Separate direction from transition length
  2. Recognize a hard color stop
  3. Review the component, not just the swatch

To reproduce a linear gradient, record its direction and stop positions as well as its colors. Two gradients with the same endpoint colors can look very different if the transition begins later or ends earlier. Inspect the full background-image declaration before sampling individual pixels from a screenshot.

Separate direction from transition length

.sample-banner {
  background-image: linear-gradient(
    90deg,
    #dceaff 0%,
    #dceaff 25%,
    #bde9d8 75%,
    #bde9d8 100%
  );
}

This original example holds pale blue through the first quarter, transitions across the middle half and finishes with pale green. At 90deg the direction runs toward the right. CSS angles start with 0deg pointing upward and increase clockwise; a graphics tool may use a different angle convention.

Reference: MDN: linear-gradient().

Recognize a hard color stop

.split-swatch {
  background-image: linear-gradient(
    to right,
    #dceaff 0% 50%,
    #bde9d8 50% 100%
  );
}

Both colors meet at 50%, producing a sharp division rather than a smooth blend. That is useful for a comparison swatch, but it is often an accidental result when a copied stop value is misplaced. Keep stop positions in the intended order and change one position at a time during diagnosis.

A gradient is an image value, so assign it to background-image or an appropriate background shorthand. It is not a background-color. Keep a plain background color underneath if the design needs a specific base, and inspect any additional background layers separately.

Review the component, not just the swatch

Test the same gradient in a tall mobile panel and a wide desktop banner. A direction toward a corner and a fixed angle can respond differently to the box’s proportions. If the source design includes a particular interpolation color space, preserve it when supported instead of assuming the midpoint will be identical in every space.

  • Record the complete gradient string and the size of the reference box.
  • Check text contrast at the least favorable part of the background.
  • Review any image or overlay composited above or below it.
  • Keep meaningful labels visible if the decorative gradient disappears.

In the handoff, name what the gradient does: surface decoration, image scrim or comparison graphic. That purpose determines whether a slight visual difference is acceptable or whether the exact stop structure carries information.
