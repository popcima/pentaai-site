Prevent Scrollbar Width Shifts with scrollbar-gutter

Reserve room for classic scrollbars with scrollbar-gutter. Test short and long panels, overlay scrollbar differences and centered content alignment.

By Penta AIPublished 28 October 20262 min read

In this guide

  1. Reserve space on the scrolling box
  2. Check whether symmetry matters
  3. Separate scrolling from other movement

If a panel becomes narrower when its vertical scrollbar appears, scrollbar-gutter can reserve that space ahead of time. It is useful when switching between a short list and a long list makes labels jump horizontally. First confirm that scrollbar space is the cause; this property does not repair every kind of layout shift.

Reserve space on the scrolling box

.result-list {
  max-block-size: 24rem;
  overflow-y: auto;
  scrollbar-gutter: stable;
}

Build two sample states in the same panel: three result rows and thirty. With classic scrollbars, stable keeps a gutter even when the list does not overflow. Overlay scrollbars float over content and do not reserve the same space, so the effect can be invisible on a system configured to use them.

Reference: MDN: scrollbar-gutter.

Check whether symmetry matters

.centered-preview {
  overflow: auto;
  scrollbar-gutter: stable both-edges;
}

When a gutter is present on one inline edge, both-edges can reserve a matching gutter opposite it. That may help a centered preview stay visually balanced. It also consumes additional room, so compare the content width before adopting it for a narrow sidebar.

Put the rule on the element that owns the scrolling. A decorative wrapper around a nested scroller does not reserve the child’s gutter for it. Use DevTools to identify the box whose client width changes when the scrollbar appears, then test the rule there.

Separate scrolling from other movement

If text still moves, check changing padding, font loading and dynamic content above the panel. A modal implementation that removes the page scrollbar may also have its own compensation logic. Do not combine a new gutter with an old hardcoded scrollbar-width padding without checking whether they reserve space twice.

  • Compare short and overflowing content at the same width.
  • Test a system with classic scrollbars and one with overlays.
  • Check left-to-right and right-to-left layouts if supported.
  • Inspect horizontal overflow after reserving extra inline space.

Record the operating-system scrollbar setting with your review screenshot. Otherwise, a teammate may correctly see no change and conclude that the CSS is broken. The acceptance criterion is stable content alignment in the relevant scrollbar mode, not a universal fixed gutter width.
