CSS Margin Collapse: Why Vertical Gaps Look Wrong

Understand collapsing block margins with a small worked example. Separate sibling spacing from parent padding and choose a repair that matches the layout.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Measure a minimal block stack
  2. Distinguish inside space from outside space
  3. Use a stack layout when every gap should match

Two vertical margins do not always add together. In normal block layout, adjoining positive margins can collapse to the larger value. A 24px bottom margin followed by a 16px top margin can produce a 24px gap, not 40px. This behavior often explains why a copied spacing value looks wrong even though DevTools shows the expected declaration.

Measure a minimal block stack

<div class="copy-stack">
  <p class="first">First paragraph</p>
  <p class="second">Second paragraph</p>
</div>
.first { margin: 0 0 24px; }
.second { margin: 16px 0 0; }

Use a plain block wrapper for this test. Adding flex or grid to the wrapper changes the rules you are investigating. Put a background on each paragraph and inspect the distance between their border boxes. The highlighted margin values alone do not tell you whether their combined space is additive.

The MDN margin-collapse reference also covers parent/child and empty-block cases. Negative margins have different combination rules; do not extend the “take the larger value” shortcut to a mix of positive and negative margins.

Distinguish inside space from outside space

If a heading’s top margin seems to push an entire colored section downward, inspect the section’s first in-flow child. Without a separating border, padding or other qualifying content, a parent and first child can share a collapsed margin. Adding more margin to that heading may move the section instead of creating the inset you intended.

.notice {
  padding-block: 24px;
  padding-inline: 20px;
  background: #eef4ff;
}
.notice > :first-child { margin-block-start: 0; }
.notice > :last-child { margin-block-end: 0; }

Here the notice owns its interior padding. The first and last content margins are reset so the boundary spacing has one owner. Keep paragraph spacing inside the notice in your ordinary type rules. This makes the component easier to inspect because outer placement and inner breathing room are explicit.

Use a stack layout when every gap should match

.stack { display: flex; flex-direction: column; gap: 24px; }
.stack > * { margin-block: 0; }

This is a separate layout choice for a component list, not a necessary rewrite of all article prose. Flex items do not collapse their margins, and gap provides the spacing between them. If your goal is only to contain child margins within a block, consider a new formatting context such as flow-root; it does not turn all sibling margins into additive gaps.

Review the first item, a middle pair and the last item after changing the layout. Then test a one-item stack and an empty state. Record which component owns padding and which parent owns inter-item spacing in your spacing system. That ownership decision prevents the same gap from being applied twice later.
