Control a Paragraph’s Last Line Without Adding Spaces

Use text-align-last for intentional paragraph endings, understand forced line breaks, and avoid manual spacing that fails when text or viewport width changes.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Keep the final line aligned to the start
  2. Inspect forced breaks and inheritance
  3. Review natural wrapping with real copy

Text-align-last controls the final line of a block and a line immediately before a forced break. It can keep the last line of a justified paragraph aligned to the reading direction without adding spaces or extra wrapper elements.

Keep the final line aligned to the start

.specimen-copy {
  max-inline-size: 42ch;
  text-align: justify;
  text-align-last: start;
}

Use a paragraph long enough to wrap across several lines, then resize its container. Start follows text direction, unlike a hard-coded left value. This is a comparison specimen, not a recommendation to justify all interface copy; uneven word spacing can reduce readability in narrow columns.

Reference: MDN text-align-last.

Inspect forced breaks and inheritance

A br introduces a forced line ending, so text-align-last can affect more than the visually final line of a paragraph containing several breaks. If several short lines unexpectedly align differently, inspect the markup before changing the rule. Also check inherited values from a surrounding content wrapper.

The default auto generally follows text-align, with special treatment for justified text: the last line aligns to the start. Setting justify on text-align-last can spread a short ending across the available width. That may create much larger gaps than the designer intended.

Review natural wrapping with real copy

Try an ending with one word, an ending with several words and a paragraph that becomes a single line at a wide viewport. Increase text size and inspect a right-to-left sample if the site supports one. Remove manual spaces and unnecessary br elements that were added merely to reproduce a screenshot.

Judge the full paragraph’s rhythm, not just the final line’s symmetry. The reading-width guide helps establish the container, while text-wrap options address line breaking rather than last-line alignment.
