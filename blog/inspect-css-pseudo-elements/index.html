How to Inspect CSS Pseudo-Elements and Missing Decorations

Find styles created by before and after pseudo-elements. Check generated content, box dimensions, positioning and clipping without changing meaningful HTML text.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Build a decoration with a visible owner
  2. Follow a missing decoration through four checks
  3. Keep meaning in the document

A small dot, underline or corner decoration may be generated by ::before or ::after rather than a separate HTML element. Inspect the owning element and its pseudo-element rules before searching your assets folder. The decoration’s appearance may come entirely from CSS, including borders, backgrounds and generated content.

Build a decoration with a visible owner

<h2 class="section-title">Project details</h2>
.section-title {
  position: relative;
  padding-inline-start: 1rem;
}
.section-title::before {
  content: "";
  position: absolute;
  inset-inline-start: 0;
  top: 0.2em;
  width: 0.25rem;
  height: 0.8em;
  border-radius: 999px;
  background: currentColor;
}

The heading contains the real text; the pseudo-element draws an accent beside it. The positioned heading supplies the decoration’s containing block. Logical inline positioning lets the accent follow the text direction. This is a small illustration of a CSS technique, not a recreation of a third-party component.

The MDN ::before reference describes generated content and the default inline display. An empty content string is useful for a purely visual shape. If content resolves to none or the rule does not apply, the decoration may never produce a box.

Follow a missing decoration through four checks

  • Select the heading in Elements and inspect its generated pseudo-element when present.
  • Confirm that the selector and content declaration apply at the current breakpoint.
  • Check dimensions, positioning and the actual color against the surface.
  • Inspect clipping and layering on ancestors if the box exists but is not visible.

A width on an ordinary inline box does not behave like a width on an inline-block or positioned box. In the example, absolute positioning makes the dimensions effective. For an inline decorative badge, choose an appropriate display value instead of copying the positioning rules mechanically.

When a mark sits in the wrong corner, inspect the containing block before changing offsets. A missing position rule on the owner can make the decoration align to a more distant ancestor. When a mark disappears only on hover, compare pseudo-element rules for both states rather than assuming the image failed to load.

Keep meaning in the document

Do not put an essential field label, validation error or article heading only into generated content. Assistive technology handling of CSS-generated text can vary, and the content should remain understandable when decorative styles are unavailable. Use real HTML for the information, then add decoration around it.

Record the owner selector, pseudo-element, content value and positioning relationship in your inspection notes. Test a long heading and a right-to-left version if the component supports them. Finally, disable the pseudo-element: the page should lose ornament, not its instructions or meaning. That simple review distinguishes a useful decoration from hidden content debt.
