Why a 100% Width Input Overflows: Check box-sizing

Trace an input wider than its container. Calculate content, padding and borders, then apply a scoped border-box rule and check the surrounding layout.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Account for each part of the box
  2. Make the intended width include the border
  3. Look outside the field if overflow remains

A field with width: 100% can still extend beyond its parent when padding and borders are added outside that width. Before reducing the field to an arbitrary percentage, inspect its box-sizing value. The correct repair depends on what the declared width is intended to include.

Account for each part of the box

/* Diagnostic specimen: intentionally wider than its parent */
.field-demo { inline-size: 300px; }
.field-demo input {
  box-sizing: content-box;
  inline-size: 100%;
  padding-inline: 12px;
  border: 1px solid #8795aa;
}

In this controlled example, a 300px content width plus two 12px paddings and two 1px borders produces a 326px border box. Margins would add further external space. Inspect the box-model diagram in DevTools and compare those values with the parent’s available content width.

Make the intended width include the border

.field-demo { max-inline-size: 100%; }
.field-demo input {
  box-sizing: border-box;
  min-inline-size: 0;
}

With border-box, the same 300px declared width includes padding and border; the content area becomes 274px. The second rule is a scoped correction to the diagnostic specimen, not a complete form stylesheet. Keep the field’s visible label and focus treatment in the real implementation.

Reference: MDN: box-sizing.

Look outside the field if overflow remains

A flex item’s minimum, a grid track, a long unbreakable value or an oversized parent can cause a similar symptom. Border-box does not make margins disappear, and it does not guarantee a usable field when its container becomes extremely narrow. Inspect ancestors before adding overflow: hidden to conceal the result.

  • Resize the container below the original 300px example.
  • Compare input, textarea and select controls rather than assuming identical defaults.
  • Check focus outlines and long entered values.
  • Confirm the field remains usable with enlarged text.

For a reusable form component, record whether dimensions describe the content box or border box. That removes a common ambiguity between a measured design width and the CSS that implements it.
