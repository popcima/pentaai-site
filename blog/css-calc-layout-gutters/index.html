CSS calc(): Build Gutters Without Guessing Pixel Widths

Use calc() to combine relative widths and fixed gutters. Check arithmetic syntax, box sizing and the containing block with a small layout example.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Express a page container rule
  2. Find the invalid part of a formula
  3. Review the box around the calculation

Use calc() when a CSS value genuinely needs arithmetic, such as a container width minus two gutters. Keep the formula connected to a clear design rule. A calculation that compensates for several unrelated offsets becomes difficult to maintain when a font, breakpoint or parent layout changes.

Express a page container rule

.page-container {
  --gutter: 1.25rem;
  box-sizing: border-box;
  inline-size: calc(100% - 2 * var(--gutter));
  max-inline-size: 72rem;
  margin-inline: auto;
}

The percentage refers to the available containing-block width, while the rem gutter follows the root font size. At a 16px root size, the two illustrative gutters total 40px. A 400px containing block therefore gives the container a 360px width before its maximum becomes relevant. Change the root size and the result should change deliberately.

Reference: MDN: calc() syntax and value types.

Find the invalid part of a formula

Put whitespace around addition and subtraction operators. Keep units inside the expression, and ensure the result is valid for the property. For example, calc(100% - 2rem) is a length-percentage expression; calc(100 - 2) produces a number and is not an ordinary width. Inspect a crossed-out declaration before trying to fix its visual result elsewhere.

/* Valid: a length divided by a number */
.tile { inline-size: calc((100% - 1rem) / 2); }

This second expression describes two equal tiles separated by one 1rem gap, but Grid is usually clearer for the complete layout. Use the formula to understand the arithmetic; do not duplicate it across every tile if a two-column grid can own the relationship centrally.

Review the box around the calculation

If the result still overflows, inspect padding, borders and box-sizing. A content-box width plus horizontal padding can exceed the space you calculated. Also check that 100% is based on the parent you intended. A nested container calculates from its own context, not automatically from the browser window.

  • Resize the containing block through the minimum and maximum design widths.
  • Increase text size to check that rem-based gutters remain sensible.
  • Remove one declaration at a time when diagnosing doubled spacing.
  • Document whether the container or its parent owns the side inset.

A useful handoff includes the rule in words: “centered, capped at 72rem, with equal 1.25rem side clearance.” That makes the formula reviewable without requiring someone to reverse-engineer a screenshot.
