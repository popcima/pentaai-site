Why a 50 Percent Border Radius Makes an Ellipse

Compare percentage radii with large fixed radii on rectangular badges, and preserve a true circle by controlling the rendered box dimensions.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Compare identical rectangles
  2. Check the border box before changing the token
  3. Test content growth, not just the empty shape

A 50% border radius produces a circle only when the rendered box is square. On a wide rectangle, the horizontal and vertical radii resolve against different dimensions, producing an ellipse. A capsule-shaped label usually needs a large length radius instead.

Compare identical rectangles

.badge {
  box-sizing: border-box;
  inline-size: 240px;
  block-size: 80px;
  display: grid;
  place-items: center;
  background: #dceaff;
}
.ellipse { border-radius: 50%; }
.pill { border-radius: 999px; }

Give two elements the badge class and one modifier each. At these dimensions, the percentage version has horizontal radii of 120px and vertical radii of 40px. The oversized equal length radii are reduced to fit, creating rounded ends with a straight middle. These are two different outlines, even though both are often called fully rounded.

Reference: MDN border-radius.

Check the border box before changing the token

A declared width and height do not necessarily describe the final outer box when padding, borders, minimum sizes or flex shrinking intervene. Measure the rendered element. For an avatar, establish equal dimensions or an appropriate aspect ratio, then decide how the image fits inside.

The slash syntax separates horizontal and vertical radii, such as 40px / 20px. It is useful for intentional elliptical corners, but adds complexity if the desired result is an ordinary pill.

Test content growth, not just the empty shape

Replace a short badge label with a longer one and enlarge text. Avoid a fixed height that clips the label merely to preserve the initial silhouette. A real button also needs enough usable interior space and a visible focus indicator. Put the chosen geometric rule in the handoff instead of the vague instruction “maximum rounding.”

Use the radius-system guide for reusable roles and the aspect-ratio guide when the box itself must stay square.
