Align Flex Items Within Lines and Lines Within a Container

Distinguish align-items from align-content in a wrapped flex layout. Create spare cross-axis space and inspect line boundaries before changing alignment.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Make the line boundaries visible
  2. Change one alignment level at a time
  3. Follow the axes, not the screenshot

In flexbox, align-items aligns items within each flex line. align-content distributes the lines within the container’s cross-axis space. A change to align-content can appear ineffective when the container does not have spare space or is configured as a single-line flex container.

Make the line boundaries visible

.tray {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
  width: 22rem;
  min-height: 20rem;
  align-items: flex-start;
  align-content: space-between;
}
.tray > .card { flex: 0 0 9rem; }
.tray > .card:nth-child(2) { min-height: 8rem; }

Use four short sample cards and give one extra content. At this width they form two lines. The tallest item helps determine its line’s size; align-items places its shorter neighbor within that line. Align-content positions the lines in the available height. The values are a debugging fixture, not a recommended fixed-size production component.

Reference: MDN align-items.

Reference: MDN align-content.

Change one alignment level at a time

Switch align-items to center and watch the short card within its line. Then switch align-content to center and watch the group of lines. Remove the minimum height and compare again. If the content uses all the available height, there may be no surplus for line distribution to make visible.

With flex-wrap: nowrap, align-content has no effect in flexbox even if the container is tall. Do not generalize that rule to every layout mode: grid and block alignment have their own behavior. An individual flex item can also override the group’s align-items value through align-self.

Follow the axes, not the screenshot

For a row in horizontal writing, the cross axis is vertical. Change flex-direction or writing mode and that visual shortcut no longer holds. Inspect the container’s direction and wrapping before treating “center” as a vertical alignment instruction.

  • Test one card, two lines and an uneven final line.
  • Use long text so items have different heights.
  • Remove temporary dimensions before shipping.
  • Retest the layout at narrow widths and enlarged text.

Use the layout comparison if the actual requirement is shared row and column tracks. Alignment properties can distribute available space, but they cannot give a flex layout the same track structure as a grid.
