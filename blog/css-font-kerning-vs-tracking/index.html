Font Kerning vs. Letter Spacing in CSS

Distinguish pair-specific kerning from overall tracking. Compare the same rendered font and specimen before changing spacing across an entire heading.

By Penta AIPublished 15 November 20262 min read

In this guide

  1. Hold the font and specimen constant
  2. Separate pair adjustment from the text-style recipe
  3. Review at the sizes that ship

Kerning adjusts spacing for particular character pairs using information in the font. Letter-spacing adds tracking across the text. If one pair looks awkward while the rest of a heading is balanced, changing global tracking may affect many good gaps without solving the actual problem.

Hold the font and specimen constant

.specimen {
  font-family: "Project Serif", Georgia, serif;
  font-size: 3rem;
  letter-spacing: normal;
}
.specimen.kerned { font-kerning: normal; }
.specimen.unkerned { font-kerning: none; }

Use your actual licensed font in place of the example family. Compare a realistic title containing pairs such as AV, To or Wa, plus the words used in your own interface. Do not assume every font has the same kerning data or that every specimen will reveal a dramatic difference.

Reference: MDN font-kerning reference.

The auto value lets the browser decide whether to apply kerning. Normal requests use of the font’s kerning information, while none disables it. Inspect the rendered face first: changing this property on a fallback font does not establish how the intended web font will look.

Separate pair adjustment from the text-style recipe

Turn off experimental letter-spacing while comparing kerning so the two effects are not confused. Then restore the intended tracking and review the complete text role. A kerning decision belongs alongside the family, weight, size and letter-spacing values, not in an isolated screenshot annotation.

Kerning is also distinct from ligatures, which can replace character combinations with a combined glyph. If the shape changes rather than just the gap, inspect the font feature involved before attributing the difference to kerning.

Review at the sizes that ship

  • Compare the same title in the loaded font and fallback face.
  • Inspect large headings and smaller labels independently.
  • Try actual punctuation, numerals and localized content.
  • Check line wrapping after any spacing change.
  • Review at normal browser zoom before drawing conclusions from enlarged screenshots.

Keep a small specimen in the design handoff with the exact font file and CSS settings. If only one image of a heading exists, the next developer cannot tell whether the observed spacing came from kerning, tracking or a different face. Use the letter-spacing guide when the whole text role needs a measured tracking change.
