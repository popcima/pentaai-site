Align Wrapped List Items with Their Markers

Compare inside and outside list markers, preserve indentation at narrow widths, and diagnose an unexpected line break before a list item’s paragraph.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Compare a long item in a narrow list
  2. Inspect the first child when a marker stands alone
  3. Review the full list structure

List-style-position controls whether a marker sits outside the item’s principal box or participates inside its content. For a long instruction that wraps, outside usually produces the familiar hanging alignment: continuation lines align with the text, not with the bullet.

Compare a long item in a narrow list

.instructions {
  max-inline-size: 28ch;
  padding-inline-start: 1.5em;
  list-style-position: outside;
}
.instructions li + li { margin-block-start: .75em; }

Apply this to a semantic ul or ol containing a sentence long enough to wrap. Toggle outside to inside in DevTools. With inside, the marker takes space at the start of the first line; following lines can begin at the item’s content edge. Keep the same font and width while comparing.

Reference: MDN list-style-position.

Inspect the first child when a marker stands alone

An inside marker followed by a block-level first child can appear on a line before that child. Check whether your markup wraps the item’s text in a paragraph or another block before adding negative margins. The problem may be the relationship between the marker and block content rather than an unexplained browser offset.

Removing all list padding can push outside markers against a clipping boundary. Restore adequate inline-start room instead of hiding overflow. Logical padding also follows writing direction more appropriately than a fixed left-only adjustment.

Review the full list structure

Test short items, long items, nested lists and a list item beginning with a paragraph. Increase text size and inspect both the first and last lines. Confirm that numbered steps remain visibly associated with the correct instruction. Avoid replacing native list semantics with a row of decorative text symbols just to align one screenshot.

Use ::marker styling for marker appearance and logical properties when reviewing right-to-left layouts.
