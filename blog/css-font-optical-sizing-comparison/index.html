Compare Optical Sizing with the Actual Font File

Review font-optical-sizing at reading and display sizes. Verify the font’s opsz support and isolate axis overrides before attributing a mismatch to CSS.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Create a controlled specimen
  2. Check the axis and the winning declaration
  3. Record an observable design decision

Optical sizing lets a supporting typeface adapt its forms to the size at which it is rendered. The difference can be subtle: it is not simply another font-size setting. Before comparing auto and none, confirm that the loaded face actually supports optical sizing.

Create a controlled specimen

.specimen {
  font-family: "Your Optical Font", serif;
  font-weight: 400;
  letter-spacing: normal;
}
.specimen--auto { font-optical-sizing: auto; }
.specimen--none { font-optical-sizing: none; }
.specimen--reading { font-size: 1rem; }
.specimen--display { font-size: 3rem; }

Replace the placeholder family with a licensed font you have loaded and verified. Show the same sentence in all four combinations of size and optical setting. Keep width, weight, spacing and browser zoom consistent. If one specimen wraps differently, inspect that outcome rather than silently changing its tracking to force a match.

Reference: MDN font-optical-sizing.

Check the axis and the winning declaration

Variable fonts commonly expose the optical-size axis as opsz. Inspect the file’s documented axes and the actual rendered face, including fallback. A CSS declaration can compute successfully even when the selected font has no optical-size behavior to apply.

Look for a low-level font-variation-settings declaration that explicitly sets opsz. An axis override can change the behavior you expected from the higher-level property. Isolate that declaration in your specimen instead of removing every variation setting from the live component, where weight or custom axes may be intentional.

Record an observable design decision

  • Capture the font file and version used for the comparison.
  • Review small labels, body text and large headings.
  • Inspect punctuation, narrow counters and dense letter combinations.
  • Compare the result at the intended size, not only in an enlarged screenshot.

Do not infer that auto always produces a dramatic difference or that none represents the designer’s intended appearance. The choice depends on the face and the layout. Record which setting you reviewed and any explicit axis values so the typography can be reproduced. Use the variable-font axis guide for the broader file-to-CSS mapping and font loading checks if both specimens are unexpectedly identical.
