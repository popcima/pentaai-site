Interpret Intersection Ratios Without Calling Them Visibility Proof

Use IntersectionObserver thresholds for geometric intersection checks, inspect the chosen root, and distinguish partial overlap from actual readable visibility.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Log a few meaningful thresholds
  2. Choose the root that matches the scrolling task
  3. Test boundaries and cleanup

IntersectionObserver reports geometric intersection between a target and a root region. An intersection ratio is not proof that a reader saw or read the content. Use it for a clearly defined layout or loading question, and identify the root and thresholds in the evidence.

Log a few meaningful thresholds

const target = document.querySelector('.review-section');
const observer = new IntersectionObserver(entries => {
  console.table(entries.map(entry => ({
    intersecting: entry.isIntersecting,
    ratio: entry.intersectionRatio,
    time: entry.time
  })));
}, { root: null, threshold: [0, 0.5, 1] });
if (target) observer.observe(target);
// End the inspection with observer.disconnect();

Root null uses the document viewport. The chosen thresholds expose entry, half-area intersection and full intersection boundaries, with an initial notification after observation. They do not request a callback for every pixel of movement. Keep the target’s dimensions known when interpreting the ratio.

Reference: MDN Intersection Observer API.

Choose the root that matches the scrolling task

For a component inside a scrolling panel, an explicit ancestor root may answer the intended question better than the viewport alone. Root margins can expand or shrink the effective region, so record them if they are used. A target taller than the available root may never reach a ratio of one.

The ordinary intersection calculation does not establish readability or absence of occlusion by every overlay. Opacity, covering content and the user’s attention are separate concerns. Avoid labeling this diagnostic as a verified view or impression without a suitable measurement definition.

Test boundaries and cleanup

Scroll the target in slowly, resize the root, and place it in a nested scrolling panel. Compare the logged ratios with the expected geometry. Disconnect when the diagnostic ends, and avoid using the callback to repeatedly change layout in a way that causes unnecessary new threshold crossings.

Use content-visibility for rendering decisions and the accessibility-tree guide for a different kind of exposure; neither is established by intersection alone.
