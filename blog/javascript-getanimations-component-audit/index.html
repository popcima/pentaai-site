List a Component’s Animations Before Pausing Them

Inspect getAnimations with a deliberate subtree scope, identify current play states and timing, and avoid assuming the returned list covers every moving image or script.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Inspect the component’s current animation objects
  2. Distinguish pausing from removing an effect
  3. Review the exact interaction that creates motion

GetAnimations returns Animation objects affecting an element, including CSS animations, CSS transitions and Web Animations. With subtree enabled, it can include descendants too. Start with a scoped inventory before pausing or canceling effects across a whole page.

Inspect the component’s current animation objects

const component = document.querySelector('.review-component');
const animations = component ? component.getAnimations({ subtree: true }) : [];
console.table(animations.map(animation => ({
  id: animation.id,
  state: animation.playState,
  currentTime: animation.currentTime,
  duration: animation.effect?.getComputedTiming().duration
})));

The returned array describes the objects found at this point in the investigation. Query again after triggering a transition or creating another effect. An empty ID is possible; it is not evidence that the animation is invalid. Inspect the target and source rule when the row needs a more useful label.

Reference: MDN getAnimations.

Distinguish pausing from removing an effect

Pause retains an animation’s current position. Cancel removes its effect and resets its playback state, which can visibly expose the underlying style. Do not use cancellation as an interchangeable pause button in a design review.

The inventory does not represent every source of motion. Video, animated image files and arbitrary requestAnimationFrame drawing loops are not automatically included as Animation objects. If motion continues after pausing this list, identify its implementation before assuming the API failed.

Review the exact interaction that creates motion

Capture the list before and after hovering, expanding or dismissing the component. Include pseudo-element effects where relevant. If you temporarily pause objects, record what you changed and restore only the intended playback states; blindly playing everything can resume effects that were already paused for a reason.

Use DevTools animation inspection for visual timing analysis and play-state guidance for a CSS animation’s own pause control.
