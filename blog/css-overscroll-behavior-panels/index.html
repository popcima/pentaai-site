Stop Scroll Chaining in a Nested Panel

Use overscroll-behavior on a nested scroll container. Compare contain and none, preserve intentional page scrolling and test the boundary with real input.

By Penta AIPublished 28 October 20262 min read

In this guide

  1. Create a bounded notes region
  2. Choose the boundary behavior
  3. Test the end of the content

Scroll chaining happens when a gesture reaches the end of one scrolling region and continues in an ancestor. In a long notes panel, that can unexpectedly move the page underneath. Apply overscroll-behavior to the actual scroll container when keeping that gesture local serves the interaction.

Create a bounded notes region

<section aria-labelledby="notes-title">
  <h2 id="notes-title">Review notes</h2>
  <div class="notes-scroll" role="region"
       aria-label="Scrollable review notes" tabindex="0">
    <!-- Place the review paragraphs here. -->
  </div>
</section>
.notes-scroll {
  max-block-size: 20rem;
  overflow-y: auto;
  overscroll-behavior-y: contain;
}
.notes-scroll:focus-visible {
  outline: 3px solid #174fa0;
  outline-offset: 3px;
}

Add enough real or sample paragraphs to make the panel overflow. The example constrains only vertical chaining; it does not request a new horizontal gesture policy. The focusable, named region gives keyboard users a clear place to enter and inspect the content.

Reference: MDN: overscroll-behavior.

Choose the boundary behavior

contain prevents continuation into another scrolling container while allowing boundary effects such as bounce where the browser provides them. none also suppresses those boundary effects. Use the narrowest behavior needed, and check supported browsers rather than assuming identical touch behavior everywhere.

This rule is not a replacement for modal semantics, focus management or an intentional background-scroll policy. A floating panel can still leave other page controls interactive. Decide whether the component is a non-modal reading region or a modal task before combining unrelated fixes.

Test the end of the content

  • Scroll to the top and bottom using a wheel or trackpad.
  • Repeat with touch on a supported mobile device.
  • Enter and leave the region with the keyboard.
  • Check whether scrolling the page outside the region still works naturally.

Also test a short-content state. If the panel has no useful scrolling, its placement and gesture handling should not feel like a dead area. Avoid applying a broad containment rule to every card on a page. In the handoff, identify the nested region and describe the specific unwanted movement that the rule prevents.
