Account for SVG Line Caps When Aligning Icons

Compare butt, round and square caps on identical SVG paths, then check how stroke width changes the visible endpoint and spacing around an icon.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Keep the geometry constant
  2. Separate endpoints from corners
  3. Review the icon at its actual size

Two SVG strokes with identical path endpoints can occupy different visible lengths. Butt caps stop at the endpoints; round and square caps extend beyond them. Inspect the painted shape before moving path coordinates to compensate for an apparent alignment error.

Keep the geometry constant

<svg viewBox="0 0 120 100" width="240" height="200" aria-hidden="true">
  <g stroke="currentColor" stroke-width="12">
    <path d="M20 20H100" stroke-linecap="butt" />
    <path d="M20 50H100" stroke-linecap="round" />
    <path d="M20 80H100" stroke-linecap="square" />
  </g>
</svg>

All three centerlines run from x=20 to x=100. With a 12-unit stroke, the round and square caps extend six units beyond each endpoint; butt does not. Round ends are semicircular while square ends stay rectangular. The generous viewBox keeps the extensions visible.

Reference: MDN stroke-linecap.

Separate endpoints from corners

Line caps affect open subpath ends. Corners where segments meet are controlled by stroke-linejoin, so changing linecap will not round a sharp elbow in the middle of a continuous path. A closed path has no exposed pair of ends to treat the same way.

Check the computed presentation when an exported attribute seems ignored: a CSS stroke-linecap declaration can override the presentation attribute. Also inspect clipping around the SVG viewport before concluding that the cap setting failed.

Review the icon at its actual size

Put the icon next to its real label and compare at the intended CSS dimensions. A cap that looks balanced in a large vector editor can alter a small icon’s apparent weight or gap. Record both the path bounds and the stroke treatment in the handoff, especially if multiple icons share a grid.

Use non-scaling strokes deliberately when resizing, and currentColor to keep decorative icons synchronized with their text.
