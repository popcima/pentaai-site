Use steps() for Discrete Animation States

Compare step timing with linear interpolation and inspect jump boundaries. Keep decorative steps separate from real progress and provide a static motion alternative.

By Penta AIPublished 19 November 20262 min read

In this guide

  1. Make the jump timing visible
  2. Count intervals and endpoint holds deliberately
  3. Test the behavior the user will receive

The steps() timing function divides progress into discrete jumps instead of continuously interpolating it. This can suit a sprite or a deliberately stepped decorative indicator. It should not be used to fabricate the apparent completion of a real task.

Make the jump timing visible

@keyframes stepped-fade {
  from { opacity: 0; }
  to { opacity: 1; }
}
.sample {
  animation: stepped-fade 4s steps(4, end) both;
}
@media (prefers-reduced-motion: reduce) {
  .sample { animation: none; opacity: 1; }
}

Use a nonessential colored square for the fixture. With end, also named jump-end, the first change waits until the end of the first interval. With start or jump-start, an initial jump occurs at the beginning. Compare the first moment as well as the end; a single middle screenshot can conceal the difference.

Reference: MDN steps timing function.

Count intervals and endpoint holds deliberately

Jump-none and jump-both change endpoint behavior rather than merely renaming start and end. Jump-none requires more than one step. Choose the form from the desired timing sequence, then inspect it at the boundaries instead of treating the numeric argument as a universal count of displayed frames.

For a sprite, the background-position distance and frame width must agree with the timing. An off-by-one distance can briefly reveal an empty region or part of another frame even when the timing function is valid. Keep the artwork geometry and timing calculation in the same fixture.

Test the behavior the user will receive

  • Inspect immediately before and after a jump.
  • Check iteration restart if the animation repeats.
  • Review pausing and any negative delay separately.
  • Confirm the static alternative communicates all necessary information.

Use a real value and semantic progress control for task completion. Keep this example’s steps confined to visual timing. If a discontinuity was unintended, compare the easing with linear in the animation inspector before changing keyframes. A clear handoff describes when each state appears, including endpoint holds, not only the total duration.
