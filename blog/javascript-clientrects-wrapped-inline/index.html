Measure the Separate Fragments of a Wrapped Inline Element

Use getClientRects for a wrapped inline label, compare the union box, and avoid mistaking border-box fragments for exact glyph or line measurements.

By Penta AIPublished 23 November 20261 min read

In this guide

  1. Measure an inline specimen after layout
  2. Keep the measurement’s meaning narrow
  3. Compare fragments with the enclosing rectangle

A wrapped inline element can occupy several rectangular fragments. GetClientRects exposes those border-box rectangles, while getBoundingClientRect gives an enclosing rectangle. The enclosing area can include space where the inline element has no visible content.

Measure an inline specimen after layout

<p style="width:180px;font:20px/1.5 sans-serif">
  <span id="wrapped">Inspect the spacing around this long inline label.</span>
</p>
<script>
const label = document.querySelector('#wrapped');
console.table([...label.getClientRects()].map(r => ({
  x: r.x, y: r.y, width: r.width, height: r.height
})));
console.log(label.getBoundingClientRect());
</script>

The span remains inline and wraps inside the paragraph. Several rectangles can describe its fragments. If you change it to an inline-block, the box model changes; the same method should not be expected to expose every line inside that single box.

Reference: MDN getClientRects wrapped inline fragments.

Keep the measurement’s meaning narrow

These are box rectangles, not tight outlines around each glyph. Complex inline content, bidirectional text and nested markup can make a simplistic “one rectangle equals one text line” assumption unreliable. Record the markup and layout context with the numbers.

The coordinates are relative to the viewport and can change with scrolling. An overlay positioned in document coordinates needs an appropriate conversion. Re-measure after relevant font, container or content changes instead of treating the first result as permanent.

Compare fragments with the enclosing rectangle

Draw temporary outlines for each fragment and a separate outline for the bounding rectangle. Narrow the paragraph and observe which parts change. Compare a short last line with the preceding longer lines to see why a single enclosing rectangle can overstate the occupied area.

Use the rectangles as diagnostic evidence for an annotation or selection design. Test the actual interactive target separately; geometric fragments alone do not certify that every intended point activates the expected control.

Compare visual bounds and layout width. Wait for the relevant font-loading phase.
