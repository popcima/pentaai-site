CSS Multiple Backgrounds: Put the Overlay in the Right Layer

Build a readable image banner with separate gradient and photo layers. Match background-size and position lists, and avoid shorthand resets during debugging.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Keep the layer lists aligned
  2. Inspect one layer at a time
  3. Review meaning and contrast separately

In a multiple-background declaration, the first image is painted closest to the viewer. Put a translucent gradient before a photo when the gradient should darken it. If the photo comes first and fully covers the box, it can hide the overlay even though both declarations are valid.

Keep the layer lists aligned

.banner {
  color: white;
  background-color: #17202d;
  background-image:
    linear-gradient(90deg, rgb(0 0 0 / 85%), rgb(0 0 0 / 20%)),
    url("/images/workshop.webp");
  background-size: cover, cover;
  background-position: center, 65% center;
  background-repeat: no-repeat, no-repeat;
  padding: 3rem 1.5rem;
}
.banner-copy { max-width: 32rem; }

Replace the sample path with an asset you have permission to use. The first size and position belong to the gradient; the second pair belongs to the photo. Keeping each list explicit makes the relationship easier to audit. The dark base color provides a surface when the image is missing.

MDN’s multiple backgrounds guide explains paint order and list repetition. A background color belongs beneath the image layers; it is not an additional image that can be moved to the front of the comma-separated list.

Inspect one layer at a time

Temporarily replace the photo with none, then restore it and remove the gradient. This separates an asset-delivery problem from an overlay-order problem. Next, move the banner through its responsive widths and examine where the subject and the text meet. A gradient that works behind a short title may leave the last line of a longer title over a bright part of the photo.

SymptomCheck
Gradient appears absentIs an opaque image listed before it?
Photo repeatsDoes its repeat entry match the photo layer?
Crop moves unexpectedlyCompare the photo’s position entry and box ratio.
Layers vanish in a variantLook for a later background shorthand reset.

A later background shorthand can reset image, size and other related properties you established earlier. When changing only the fallback color in a component variant, use background-color. Inspect the winning declaration before adding more specificity.

Review meaning and contrast separately

Treat decorative background photography differently from an image that carries essential information. If readers need the image to understand a diagram or product detail, use meaningful image markup with a text alternative instead of hiding the information in CSS.

Measure contrast where the text actually lands, using the final image, overlay and responsive layout. The example opacity values are starting points, not a guaranteed contrast result. Test a long headline and the fallback surface with the image blocked. Save the layer order and focal-point decision with the asset so the next image replacement gets the same review.
