Mark Product Names for Translation Without Freezing the Sentence

Use translate=no on stable names or identifiers, preserve translatable surrounding copy, and distinguish localization guidance from language metadata.

By Penta AIPublished 23 November 20261 min read

In this guide

  1. Mark the smallest meaningful range
  2. Separate translation policy from language
  3. Review the localized page as a whole

The translate attribute tells localization tools whether text and translatable attributes should be translated. Use translate="no" for a stable product name or exact identifier when that matches the content policy. Keep the surrounding instruction available for translation.

Mark the smallest meaningful range

<p>Open <span translate="no">Penta AI</span> to inspect the page.</p>
<p>Keep the token name <code translate="no">--surface-panel</code> unchanged.</p>

The product name and token are protected ranges; the explanatory sentences are not. This expresses an editorial intention to translation tools. It does not run a translation service or guarantee identical behavior in every tool.

Reference: MDN HTML translate no product names.

Separate translation policy from language

Lang identifies a language for pronunciation and other language-sensitive behavior. Translate controls a localization decision. A name can need both a known language and a no-translation policy; one attribute is not a replacement for the other.

The translate value can be inherited. A broad no value on a wrapper may accidentally freeze help text, button instructions or error messages. Use yes on an appropriate descendant when it must remain translatable within a protected region, or narrow the original protected range.

Review the localized page as a whole

Test the page with the actual translation workflow the product supports. Check whether the protected spelling survives, the surrounding sentence is grammatical and the longer translated text still fits. Do not infer translation quality from the presence of the attribute alone.

Keep a short content policy listing which names, code tokens and identifiers remain stable. Some product terms may have official localized names, so a blanket rule that all branded words must stay unchanged can be wrong. Review titles and tooltips as well as visible body text where those attributes carry translatable content.

Declare content language separately. Review unknown-direction text.
