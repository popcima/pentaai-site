Pause a CSS Animation Without Restarting It

Use animation-play-state for an explicit pause control. Keep the control usable, distinguish pausing from resetting and provide a reduced-motion experience.

By Penta AIPublished 16 November 20262 min read

In this guide

  1. Connect the control to a real state
  2. Keep pause, reset and reduced motion separate
  3. Test interruption and restoration

Animation-play-state: paused stops a CSS animation at its current position. Returning it to running resumes from that point rather than restarting the sequence. Use an explicit control when users need to manage motion; hover-only pausing does not provide the same path for keyboard and touch users.

Connect the control to a real state

<button id="pause-demo" type="button" aria-pressed="false">
  Pause preview motion
</button>
<div class="motion-demo" aria-hidden="true"></div>
.motion-demo { animation-play-state: running; }
.motion-demo.is-paused { animation-play-state: paused; }
const pause = document.querySelector("#pause-demo");
const demo = document.querySelector(".motion-demo");
pause.addEventListener("click", () => {
  const paused = pause.getAttribute("aria-pressed") !== "true";
  demo.classList.toggle("is-paused", paused);
  pause.setAttribute("aria-pressed", String(paused));
});

This wiring assumes a decorative demo already has an animation defined. The button’s label stays stable while its pressed state reflects the pause choice. Provide a visible pressed treatment and focus indicator in the actual component.

Reference: MDN animation-play-state reference.

Keep pause, reset and reduced motion separate

Removing the animation or changing its identity can have different effects from pausing it. If the product needs a replay button, specify replay as a separate action rather than describing a class removal as pause. When several animations run on one element, inspect the corresponding play-state list.

Reduced motion should present a useful alternative, often a static preview. If no motion is running in that mode, decide whether the pause control should be omitted or explained. Do not leave a control that appears to do meaningful work when the only effect has already been disabled.

Test interruption and restoration

  • Pause at several points and confirm the visual position holds.
  • Resume and check that the sequence continues rather than jumping to the start.
  • Activate the control with keyboard and touch.
  • Check a saved pause choice after the component rerenders.
  • Verify the information remains understandable in a static state.

Pausing decorative motion should not pause an unrelated operation such as a real upload. Keep progress feedback accurate while the animation changes. Pair this state wiring with the toggle-button guide so visual motion and exposed control state remain synchronized.
