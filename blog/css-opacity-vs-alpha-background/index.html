Fade a Background Without Fading Its Text

Compare element opacity with alpha colors on a note surface. Keep labels opaque, inspect the composited background and review hidden interaction states.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Give the two effects separate specimens
  2. Inspect the surface underneath
  3. Review what a faded element can still do

Setting opacity on a card fades the card as a group, including its text and descendants. If only the background should be translucent, put alpha in the background color instead. Increasing a child’s opacity back to 1 does not undo the parent’s group compositing.

Give the two effects separate specimens

.faded-card {
  background: #174fa0; color: white;
  opacity: .5;
}
.translucent-card {
  background: rgb(23 79 160 / .12);
  color: #102846;
}

These examples express different design intentions. The first intentionally fades the whole surface. The second keeps the label fully opaque while allowing the surrounding background to contribute to the card’s appearance. They are not intended to produce matching pixels.

Reference: MDN: opacity and compositing.

Inspect the surface underneath

An alpha color does not have one final appearance independent of its backdrop. Compare the card over the actual light, dark or image surface where it will be used. Check the rendered text/background pair rather than calculating contrast against the uncomposited blue alone.

If a photograph is involved, review both bright and dark regions behind the label. A separate solid text surface or stronger overlay may produce a more dependable result than a subtle tint. Record the backdrop together with any approved color value.

Review what a faded element can still do

  • Check whether an opacity-zero control remains focusable or clickable.
  • Confirm disabled appearance is paired with the intended native behavior.
  • Inspect stacking when opacity is less than 1.
  • Test text and icons in hover, focus and selected states.

Opacity changes appearance; it is not a general interaction switch. If the card should become unavailable, choose the appropriate semantic behavior independently. For a token library, distinguish a translucent surface color from a component opacity value in the token names and usage notes. That prevents a designer’s “soft background” request from unexpectedly weakening every label and focus indicator inside it.
