How to Write Alt Text for UI Screenshots and Icons

Choose image alternatives by purpose: informative screenshots, decorative artwork and linked icons. Keep complex instructions in nearby text instead of overloaded alt text.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Classify the image before describing it
  2. Make a screenshot support the instruction
  3. Avoid duplicate names inside controls
  4. Review alternatives when the artwork changes

Write an image alternative for the job the image performs on that page. A screenshot explaining a selected setting needs different text from the same screenshot used as decoration. Begin by asking what the reader would miss if the image were unavailable, then supply that information in the most useful place.

Classify the image before describing it

Image purposeAlternative approach
Screenshot showing a selected settingDescribe the setting or result that matters.
Decorative interface artwork beside equivalent textUse an empty alt attribute.
Image-only linkDescribe the destination or action.
Complex diagram with several stepsProvide a short alternative and full nearby explanation.

The W3C alt decision tree organizes these decisions around context and function. Empty alt and a missing alt attribute are different choices: explicitly mark a decorative image with alt="" instead of leaving its treatment ambiguous.

Make a screenshot support the instruction

<figure>
  <img src="/images/export-settings.webp" width="960" height="600"
    alt="Export settings with SVG selected as the file format.">
  <figcaption>Choose SVG when exporting this vector icon.</figcaption>
</figure>

This is illustrative markup for a screenshot that actually shows that state. The alternative names the relevant selection rather than cataloging every toolbar and pixel. If the article already explains the state completely and the image adds no information, an empty alternative may be more appropriate. Review the whole paragraph and caption together before deciding.

For a screenshot containing an error message, include the important error wording in real article text as well. That makes it searchable, selectable and available without opening the image. Avoid embedding an entire tutorial in one long alt attribute; readers should be able to navigate the instructions as ordinary headings and paragraphs.

Avoid duplicate names inside controls

<a href="/downloads/">
  <img src="/icons/download.svg" alt="" width="20" height="20">
  Download files
</a>

Here the visible link text already names the destination. Repeating “Download files” in the icon’s alternative can make the link name redundant. An image-only link would need an accessible name from the image alternative or another suitable labeling method. Do not substitute a filename such as download-final-v3.svg for a meaningful action.

Review alternatives when the artwork changes

Treat alt text as part of the content record. If a screenshot changes from SVG selected to PNG selected, the alternative must change with it. If an image moves from an explanatory guide to a decorative homepage card, reconsider its purpose rather than copying the old text unchanged.

Read the page with images unavailable and then inspect it with a screen reader. Confirm that the main instructions still work and that decorative images do not create noise. Keep keyword targeting out of this decision: a relevant, accurate alternative helps people understand the page, while a list of search phrases does not describe the image’s purpose.
