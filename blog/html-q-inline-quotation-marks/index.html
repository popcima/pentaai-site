Mark Up Inline Quotations Without Doubling the Quotes

Use q for a genuine inline quotation, keep source attribution visible, and inspect generated quotation marks before adding punctuation by hand.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Keep the quotation separate from its attribution
  2. Distinguish a source attribute from a visible citation
  3. Review copied and localized text

Use q for a short inline quotation, not merely to decorate a slogan. Browsers commonly supply quotation marks around the element. If an imported text string already contains outer marks, wrapping it in q can produce doubled punctuation.

Keep the quotation separate from its attribution

<p>
  In this fictional editing example, the reviewer wrote
  <q>Keep the label beside the control.</q>
</p>

The sentence is explicitly fictional demonstration copy, not a testimonial or a reported product result. No literal opening or closing marks appear inside q. In a real article, reproduce the quotation accurately and identify its actual source in nearby text with an appropriate link.

Reference: MDN q.

Distinguish a source attribute from a visible citation

The cite attribute on q can point to the source document, but it does not automatically render an attribution link for readers. Provide one in ordinary content when needed. Use blockquote for a longer block quotation instead of enlarging an inline q until it happens to look like a pull quote.

Inspect the browser’s generated quotation styling, including nested quotations and the language context. A global reset or custom pseudo-element rule can remove or duplicate marks. Do not add another pair blindly before checking the computed styles.

Review copied and localized text

Paste the rendered sentence into the places readers are likely to use it and check whether the quotation remains understandable. Review the markup with styles disabled, then with your production stylesheet. For translated content, set the correct language and review punctuation conventions with someone who knows that language.

Before publishing, verify the exact wording, attribution and permission requirements for the actual quoted material. The language guide helps establish context; the figure-caption guide covers explanatory text accompanying illustrations rather than quotations.
