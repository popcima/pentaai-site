Restore Holes in a Compound SVG Path with the Right Fill Rule

Inspect compound paths with nonzero and evenodd, verify contour direction, and avoid painting a fake background-colored hole into a reusable icon.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Compare the same two contours
  2. Check whether the export is actually compound
  3. Place the icon on contrasting surfaces

When a hole disappears from an exported SVG icon, inspect the compound path and its fill rule. Evenodd treats nested regions by crossing parity; nonzero also depends on contour direction. A white rectangle over a filled shape is not a transparent hole.

Compare the same two contours

<svg viewBox="0 0 100 100" width="160" height="160" aria-hidden="true">
  <path fill="currentColor" fill-rule="evenodd"
        d="M10 10H90V90H10Z M30 30H70V70H30Z" />
</svg>

This original square-ring specimen has two clockwise contours in one path. Evenodd leaves the inner square open. Change the rule to nonzero without editing the coordinates and the interior fills. Then reverse only the inner contour to investigate how winding direction changes the nonzero result.

Reference: MDN fill-rule.

Check whether the export is actually compound

Fill-rule does not make two independent sibling rectangles subtract from each other. The relationship in this example exists inside one compound path. If an editor exported separate filled elements, inspect its boolean-path or export settings instead of repeatedly changing a rule on the wrapper.

A CSS fill-rule can override the presentation attribute. A clipping path may also involve clip-rule rather than the fill rule you are examining. Identify which operation produces the visible boundary before changing the artwork.

Place the icon on contrasting surfaces

Test a light surface, a dark surface and a patterned surface. A true hole exposes each background; a painted white patch does not. Check small-size legibility after optimization and compare the optimized path with the original export. Preserve the intended fill rule when moving the SVG into a shared component.

Use currentColor icons for theme-aware paint, and check repeated SVG identifiers if the failure only appears when several instances are present.
