Style Link Underlines Without Losing Readability

Tune underline offset and thickness for inline links. Test wrapped text, descenders and focus states while preserving a clear visual cue beyond link color.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Use native text decoration first
  2. Build a specimen that exposes weak spots
  3. Keep link purpose clear in the words

An underline helps readers distinguish an inline link from surrounding prose without relying only on color. Adjust its thickness and distance from the text to suit the typeface, then test a link that wraps. A decorative border or background trick may look good on one line and fail when the text spans two.

Use native text decoration first

.article-copy a {
  color: #174fa0;
  text-decoration-line: underline;
  text-decoration-thickness: 0.08em;
  text-underline-offset: 0.18em;
  text-decoration-skip-ink: auto;
}
.article-copy a:hover { text-decoration-thickness: 0.14em; }
.article-copy a:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 3px;
}

The em values scale with the text size. They are specimen values to evaluate with your actual font, not universal ideal settings. The underline remains present before hover, and keyboard focus has its own visible treatment.

MDN’s underline-offset reference explains that offset is separate from the text-decoration shorthand and affects underlines rather than every decoration type. Set it explicitly when your design depends on a particular distance.

Build a specimen that exposes weak spots

Use a sentence containing letters with descenders, such as “Review typography and spacing,” and make the link long enough to wrap at a narrow width. Compare regular and bold linked text. Inspect whether the underline crowds the next line, disappears around too many glyphs or looks disconnected from its text.

SpecimenReview goal
Short link in body copyClearly identifiable before interaction.
Two-line linkDecoration follows both line fragments.
Link with g, p, q and yDescenders remain readable.
Focused linkKeyboard location is unambiguous.
Link on a colored surfaceText and focus treatment remain visible.

Avoid adding padding that unexpectedly changes the line box just to move an underline. Use the underline properties for the decoration itself. If you need a custom animated treatment, compare it with the native baseline under wrapping, zoom and reduced motion before replacing the simpler approach.

Keep link purpose clear in the words

A refined underline cannot rescue vague link text. “Read the font-loading checklist” communicates more than several identical “Learn more” links scattered through a guide. Keep the label useful in its surrounding sentence and make the destination predictable.

Review hover, focus and visited styling in the page’s supported themes. Do not remove outlines without an equivalent focus indication. Use the contrast workflow for the actual text and surface combinations instead of assuming blue always passes.

Save the chosen values as part of the body-link style, distinct from navigation buttons or card links. A single global link rule can accidentally underline logos or disrupt a button treatment. Scope the typography decision to the places where readers benefit from an inline text cue.
