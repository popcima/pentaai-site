Fit an SVG ViewBox with meet, slice or none

Compare SVG aspect-ratio alignment when the viewport shape differs from the viewBox. Check empty space, cropping and distortion as separate design decisions.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Use mismatched shapes to reveal the choice
  2. Choose alignment as well as scaling
  3. Review geometry and content boundaries

PreserveAspectRatio controls how an SVG viewBox fits a viewport with a different shape. Meet shows the whole viewBox while preserving proportions; slice fills the viewport and can crop it. None allows nonuniform scaling, which can distort circles and other geometry.

Use mismatched shapes to reveal the choice

<svg viewBox="0 0 100 100" width="240" height="120"
     preserveAspectRatio="xMidYMid meet" aria-hidden="true">
  <circle cx="50" cy="50" r="40" fill="#2878dd" />
</svg>

The square coordinate region is displayed in a wide viewport. Meet keeps the full circle and leaves side space. Compare xMidYMid slice with the same viewport, then none. Make the viewport boundary visible in the fixture so unused space and clipping are easy to distinguish.

Reference: MDN preserveAspectRatio.

Choose alignment as well as scaling

The x and y alignment keywords determine how remaining space or excess artwork is distributed. Centering is only one option. If a mark must stay attached to a particular edge, test the corresponding alignment with the actual drawing and both wide and tall viewport shapes.

The normal SVG scaling use of this attribute depends on a viewBox; an SVG image element has additional behavior described in the reference. Also distinguish the SVG’s internal mapping from CSS sizing of an outer img element. A surrounding object-fit rule and an internal SVG setting can answer different fitting questions.

Review geometry and content boundaries

  • Compare circles, squares and text for accidental stretching.
  • Check every viewport ratio used by the component.
  • Inspect clipping of strokes near the edge.
  • Test meaningful artwork rather than only a centered placeholder.

Do not select none simply to remove empty space if it changes the brand mark’s proportions. If a genuinely different composition is needed, prepare the appropriate asset instead of stretching one drawing into every slot. Use the viewBox sizing guide to establish the coordinate region first, then document the chosen alignment and cropping policy.
