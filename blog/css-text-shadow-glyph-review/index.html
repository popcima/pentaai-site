Review Text Shadows at the Actual Reading Size

Separate glyph shadows from box shadows, inspect offsets and blur one value at a time, and avoid relying on a glow to make a variable background readable.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Use one shadow before stacking several
  2. Inspect the correct shadow model
  3. Check small text and alternate rendering

Text-shadow follows the glyphs rather than the element’s rectangular box. A restrained shadow can support a deliberate visual treatment, but a blurred halo can also make small labels harder to read. Judge it at the actual display size and background.

Use one shadow before stacking several

.hero-label {
  color: #fff;
  background-color: #203b30;
  padding: .5em;
  text-shadow: 0 1px 2px rgb(0 0 0 / .35);
}

The specimen gives white text a known dark surface before adding a small shadow. Compare against text-shadow: none, then change the vertical offset and blur separately. Keep font weight and size fixed so the shadow’s contribution is visible. These values are an inspection starting point, not a universal recipe.

Reference: MDN text-shadow.

Inspect the correct shadow model

Text-shadow uses horizontal offset, vertical offset, optional blur and color. It does not accept the spread or inset controls used by box-shadow. Comma-separated shadows can stack several effects, with the first listed drawn in front. An inherited text shadow can also reach labels that were never intended to have a glow.

Large blur does not establish reliable readability over every part of a photograph. Compare the composited text against the lightest and darkest expected background regions, and use a stable surface or overlay when needed.

Check small text and alternate rendering

Inspect the real text at normal zoom, then enlarged. Compare a short heading with a dense line of secondary copy; an effect suitable for one may damage the other. Review themes and forced-colors behavior without assuming the decorative shadow will survive unchanged.

Remove inherited shadows from controls that need crisp edges, and verify that any decorative treatment still leaves the content readable. Use the box-shadow guide for rectangular surfaces and the contrast workflow for the final text/background combination.
