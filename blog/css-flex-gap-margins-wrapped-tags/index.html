Separate Flex Gaps from Margins in a Wrapping Tag Row

Use gap for spacing between flex items, padding for outer space, and inspect margins or distributed alignment when visible gaps exceed the declared value.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Separate the three spacing responsibilities
  2. Inspect all contributors to the visible distance
  3. Test one item and a partial final line

Gap adds spacing between flex items and lines, not padding around the container’s outer edge. A wrapping tag row becomes easier to reason about when the container owns internal gaps and padding, while each tag avoids an extra spacing margin.

Separate the three spacing responsibilities

.tag-row {
  display: flex;
  flex-wrap: wrap;
  gap: 16px 12px;
  padding: 16px;
  justify-content: flex-start;
}
.tag-row > .tag {
  margin: 0;
  flex: 0 0 100px;
}

For this row-direction specimen, 16px separates lines and 12px separates items within a line. Padding creates the outside breathing room. Fixed 100px items make the wrapping threshold easy to observe; production tags may instead size to their actual labels.

Reference: MDN gap.

Inspect all contributors to the visible distance

If the gap looks larger than 12px, check child margins, item dimensions and alignment such as space-between. Distributed free space can add separation beyond the declared gutter. Setting gap does not cancel old margins inherited from a previous spacing approach.

Wrapping flex lines distribute their items independently. The final short line does not inherit a column grid from the line above. If all tags must align in shared columns, consider whether Grid better expresses the requirement.

Test one item and a partial final line

Compare a single tag, a full row and a row that wraps by one item. Measure both an interior gap and the distance to the container edge. Remove an item and confirm no leftover end margin survives. Increase text size before deciding whether fixed item widths are appropriate for real labels.

Use spacing tokens to name the chosen distances and flex alignment guidance when line distribution adds space beyond the gutters.
