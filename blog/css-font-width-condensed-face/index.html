Choose a Condensed Font Face Instead of Squashing Text

Inspect font width support and available faces, distinguish font selection from transform scaling, and verify layout with the actual loaded font.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Compare a supported family at two widths
  2. Inspect selection before manipulating geometry
  3. Check fit without sacrificing readability

A condensed font face has glyphs designed for a narrower proportion. Font-width selects an available width; it does not mechanically squeeze any arbitrary font. If the family has no matching width capability, changing the property may not produce the expected visual difference.

Compare a supported family at two widths

.width-specimen {
  font-family: "Your Width Family", sans-serif;
  font-stretch: condensed;
  font-width: condensed;
}
.width-specimen.normal {
  font-stretch: normal;
  font-width: normal;
}

Replace the specimen family with an actual loaded family offering condensed faces or a supported width axis. The older font-stretch name is included for browsers using that property name; verify which declaration your target browser accepts. The example does not download a font or establish an appropriate @font-face range by itself.

Reference: MDN font-width.

Inspect selection before manipulating geometry

Confirm the rendered font, available faces and face descriptors. A variable font needs the intended axis and a correctly exposed range. Low-level font-variation-settings can also complicate the result if it directly controls width. Change one layer at a time while recording the actual font file.

Transform: scaleX changes painted geometry without providing the same layout behavior or designed glyph shapes. Letter-spacing changes gaps between characters instead of selecting narrower letterforms. Neither is a drop-in replacement for a condensed face.

Check fit without sacrificing readability

Compare the real heading, a long label, numbers and punctuation at the intended size. Measure line breaks and the surrounding layout as well as the apparent width. Disable the web font temporarily to review fallback behavior. Do not compress critical text indefinitely to preserve a fixed screenshot; allow the container or line count to adapt.

Use the variable-font axis guide to map file capabilities and the font-loading checklist when the requested face never appears.
