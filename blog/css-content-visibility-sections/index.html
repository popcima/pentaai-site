Evaluate content-visibility for Long Page Sections

Try content-visibility on below-screen sections with an intrinsic size estimate. Check scrolling, search, accessibility and measured rendering behavior.

By Penta AIPublished 28 October 20262 min read

In this guide

  1. Choose a substantial section
  2. Make the estimate accountable
  3. Review discovery and interaction

content-visibility: auto lets the browser skip some rendering work for content that is not currently relevant to the user. It can be useful on long pages with substantial independent sections. It does not remove the content from the document, and it should be evaluated with real measurements rather than added as a blanket performance claim.

Choose a substantial section

.reference-section {
  content-visibility: auto;
  contain-intrinsic-size: auto 30rem;
}

Use this on a self-contained reference section below the initial viewport, not on the page’s main heading or an essential control. The intrinsic-size declaration supplies a placeholder estimate while rendering is skipped; the auto part can use a remembered size after the section has been rendered.

Reference: MDN: content-visibility.

Make the estimate accountable

The 30rem value is illustrative. Measure representative section heights before choosing an estimate. If a section is usually much taller, a small placeholder can change the scroll range noticeably when content becomes visible. Test sections with short text, long text and images rather than deriving the estimate from one ideal sample.

Keep image dimensions and ordinary layout constraints correct inside the section. Skipping off-screen rendering does not excuse missing media dimensions or fixed text heights. Those problems can still appear when the browser renders the content.

Review discovery and interaction

With auto, off-screen content remains available to user-agent features such as find-in-page and keyboard navigation. That makes it different from hiding a section with display: none. Nevertheless, test the actual page with the assistive technologies and browsers you support, especially if it contains conditionally hidden descendants.

  • Use find-in-page to locate text in an off-screen section.
  • Follow a direct fragment link into the section.
  • Tab through any controls as they become relevant.
  • Scroll quickly down and back up while watching layout stability.

Compare a repeatable performance recording with the rule enabled and disabled, using the same content and environment. Report the actual observation and tradeoffs. Do not describe a shorter DOM or reduced network transfer: this rendering feature does not by itself remove nodes or stop images and scripts from being requested. Keep the optimization only when the measured benefit and reading experience justify it.
