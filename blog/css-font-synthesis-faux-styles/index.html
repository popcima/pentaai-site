Spot Faux Bold and Italic with CSS font-synthesis

Diagnose synthetic bold or italic text. Inspect the loaded faces and font declarations before deciding whether to disable synthesis for a type specimen.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Create a focused comparison
  2. Check the font declarations
  3. Decide where synthesis should remain available

A heading can look heavier than its intended font because the browser is synthesizing a missing bold face. Italic text can similarly be slanted from an upright face. Before changing letter spacing or choosing another font, check whether the requested weight and style actually have a matching font resource.

Create a focused comparison

<p class="type-sample">Regular <strong>Bold</strong> <em>Italic</em></p>
.type-sample { font-family: "Project Sans", sans-serif; }
/* Diagnostic toggle: compare both settings. */
.type-sample { font-synthesis: none; }

Use the real project family in this specimen. Toggle synthesis only while watching the rendered faces and network requests. If the appearance changes, investigate the missing face. Disabling synthesis does not download or create the correct bold or italic design.

Reference: MDN: font-synthesis.

Check the font declarations

@font-face {
  font-family: "Project Sans";
  src: url("/fonts/project-bold.woff2") format("woff2");
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}

This is a declaration pattern for a real file you supply. The weight and style descriptors should describe that file accurately. A regular file labeled as 700 is not a substitute for a designed bold face. For a variable font, declare its actual supported range and inspect whether the requested style has its own resource or axis.

Check the request status, response type and rendered-font information. A successful response alone does not prove the intended face is used on every glyph. Missing character coverage can cause part of a phrase to fall back to another family, making the problem look inconsistent.

Decide where synthesis should remain available

For a tightly controlled brand specimen, disabling synthesis can expose missing assets during review. For broad reading content, a global prohibition deserves more care because fallback fonts may not include every requested style. Review emphasis and hierarchy in loading and failure states before applying the setting across the entire site.

  • Compare regular, bold, italic and bold italic in the actual text size.
  • Include accented characters and symbols used by the content.
  • Simulate a font load failure and inspect the fallback.
  • Check that strong and emphasized text remain understandable.

Record the family, face files, supported weights and synthesis policy in the typography handoff. A screenshot of the final heading is useful, but the resource mapping is what makes the result reproducible on another machine.
