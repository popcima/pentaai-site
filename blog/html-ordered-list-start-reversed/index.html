Continue or Reverse an Ordered List with Native HTML

Set ordered-list numbering with start, reversed and item values. Keep the document’s reading order meaningful instead of using CSS to fake a sequence.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Continue a sequence after an interruption
  2. Distinguish countdown numbering from DOM reversal
  3. Keep visible numbers and content meaning aligned

Use an ordered list when the sequence of items matters. HTML can continue a sequence with start, count downward with reversed, and set a particular item’s ordinal with value. Those attributes change numbering without asking CSS to reorder the content.

Continue a sequence after an interruption

<ol start="4">
  <li>Review the responsive layout.</li>
  <li>Check the keyboard path.</li>
  <li>Record unresolved issues.</li>
</ol>

The start value is an integer even when the marker style is alphabetic or Roman. This example begins at the fourth step because earlier steps would exist elsewhere in the same document. Do not start at four simply to make a decorative label look interesting; readers should understand the continued sequence.

Reference: MDN ordered list attributes.

Distinguish countdown numbering from DOM reversal

<ol reversed start="3">
  <li>Third-place example</li>
  <li>Second-place example</li>
  <li>First-place example</li>
</ol>

This illustrative ranking is already written in the intended reading order. Reversed makes its numbering descend; it does not reverse the elements themselves. Without an explicit start, a reversed list begins from its number of list items. Adding or removing an item can therefore change the starting number.

An integer value on a list item establishes that item’s ordinal and affects the numbering that follows. Use it for a real interruption or special numbering requirement, and test dynamic insertions. For a normal uninterrupted list, letting the browser calculate the sequence is simpler than manually maintaining every value.

Keep visible numbers and content meaning aligned

  • Read the items in DOM order without CSS.
  • Add and remove a middle item and inspect the sequence.
  • Check copy, print and screen-reader behavior for your supported environment.
  • Avoid duplicating typed numbers beside native markers.

Use marker styling for visual treatment and CSS counters for appropriate generated section labels. A list’s ordinal is not always a sufficient stable identifier: if another document needs to refer permanently to a requirement, give that requirement a durable ID in the content model.
