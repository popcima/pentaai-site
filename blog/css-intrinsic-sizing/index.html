min-content, max-content and fit-content: Size CSS to the Text

Choose an intrinsic width for labels and compact panels. Compare min-content, max-content and fit-content while checking available space and long values.

By Penta AIPublished 28 October 20262 min read

In this guide

  1. Compare one label at three widths
  2. Choose a wrapping policy for the real value
  3. Inspect the surrounding layout

Use intrinsic sizing when a box should respond to its content instead of receiving an arbitrary pixel width. min-content favors the smallest width available through normal wrapping opportunities. max-content considers the width without soft wrapping. fit-content fits between those content limits while considering the available space.

Compare one label at three widths

<p class="label compact">Review the navigation spacing</p>
<p class="label expanded">Review the navigation spacing</p>
<p class="label fitted">Review the navigation spacing</p>
.label { padding: .75rem; border: 1px solid #aeb8c7; }
.compact { inline-size: min-content; }
.expanded { inline-size: max-content; }
.fitted { inline-size: fit-content; }

Use a plain block parent for this comparison. In the compact version, the longest unbreakable segment sets an important lower bound. The expanded version can exceed a narrow parent. The fitted version responds to available space, but it cannot make every unbreakable child become smaller.

Reference: MDN: fit-content sizing.

Choose a wrapping policy for the real value

.file-badge {
  box-sizing: border-box;
  inline-size: fit-content;
  max-inline-size: 100%;
  overflow-wrap: anywhere;
}

This second specimen is for a badge containing an unpredictable filename. The maximum constrains the box and the wrapping rule gives the text additional break opportunities. Decide whether breaking the value is appropriate for your content; a compact navigation label and a machine-generated identifier have different needs.

Inspect the surrounding layout

Grid and flex sizing can introduce their own minimums and free-space distribution. If the box behaves differently after moving into a card row, inspect those parent rules before adding another width override. Also distinguish the fit-content keyword from the fit-content() function used in sizing contexts such as grid tracks.

  • Test short copy, multiple words and one long unbroken value.
  • Resize the parent rather than only the browser window.
  • Increase text size and inspect padding as part of the total box.
  • Check whether neighboring controls still have enough room.

For handoff, explain the behavior in words: “grow with the label, but wrap inside the available space.” That rule is more durable than the measured width of one sample label.
