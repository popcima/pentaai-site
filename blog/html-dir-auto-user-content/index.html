Let Unknown User Text Choose Its Base Direction

Use dir auto for text whose direction is not known in advance, inspect punctuation and leading characters, and keep language identification separate from direction.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Compare two standalone review notes
  2. Test the characters that establish direction
  3. Review mixed text without rearranging the source

Use dir="auto" for user text whose base direction is not known in advance. The browser generally determines direction from the first strong directional character. It does not translate the content or identify its language for you.

Compare two standalone review notes

<p dir="auto">Review the spacing beside the label.</p>
<p dir="auto" lang="ar">مراجعة التصميم</p>
<style>
[dir="auto"] { text-align: start; }
</style>

The English note begins with left-to-right text, and the Arabic specimen begins with right-to-left text. Start alignment follows the resolved direction. The known Arabic specimen has lang="ar" separately; an application should not guess a language merely because direction resolves to right-to-left.

Reference: MDN dir.

Test the characters that establish direction

Leading punctuation or digits may not determine the base direction, so inspect the first strong character rather than only the first visible symbol. A Latin identifier at the start of an otherwise right-to-left note can affect the result. Use explicit direction when the application already knows the correct value.

For a small unknown-direction name embedded inside a larger sentence, bdi can be the more appropriate isolation pattern. A whole paragraph and an inline fragment do not always need the same wrapper or alignment policy.

Review mixed text without rearranging the source

Try a note beginning with a number, one beginning with an English product identifier and one containing punctuation near a right-to-left phrase. Copy the text to a plain editor and confirm that the logical source order remains correct. Do not manually reverse characters to imitate the desired visual order.

Inspect a live input or textarea separately if users edit the text; caret movement and selection also matter. Compare the bdi guide for inline isolation and language markup for pronunciation and language-specific behavior.
