Insert a Token into a Textarea Without Losing the Selection

Use setRangeText to replace a selected range, place the caret deliberately, and synchronize the preview explicitly after a programmatic text edit.

By Penta AIPublished 24 November 20262 min read

In this guide

  1. Replace the selected range and move the caret after it
  2. Treat offsets as string positions, not visible glyph counts
  3. Test insertion, replacement and editing history

SetRangeText replaces a range inside a textarea and lets you choose the resulting selection. It is useful for an “insert token” action that should replace selected text or insert at the caret. Rebuilding the whole value manually is unnecessary for that bounded operation.

Replace the selected range and move the caret after it

<label for="notes">Review notes</label>
<textarea id="notes">Panel spacing</textarea>
<button id="insert-token" type="button">Insert color token</button>
<pre id="notes-preview"></pre>
<script>
const notes = document.querySelector('#notes');
const preview = document.querySelector('#notes-preview');
function render() { preview.textContent = notes.value; }
document.querySelector('#insert-token').addEventListener('click', () => {
  notes.setRangeText('--surface-panel', notes.selectionStart, notes.selectionEnd, 'end');
  notes.focus();
  render();
});
notes.addEventListener('input', render);
render();
</script>

The end selection mode leaves the caret after the replacement. A collapsed selection inserts without removing surrounding text. The explicit render call keeps the preview synchronized with this programmatic change rather than assuming an ordinary input event will do it.

Reference: MDN textarea setRangeText selection insertion.

Treat offsets as string positions, not visible glyph counts

Selection offsets use the control’s string indexing model. Emoji and combined characters can occupy more than one code unit, so an externally computed visual-character count may identify the wrong boundary. Using the control’s current selection avoids inventing a separate counting scheme for this operation.

For a larger editor, save the intended range if an intervening dialog changes focus or selection. Check that the stored range still belongs to the current value before applying a delayed insertion.

Test insertion, replacement and editing history

Insert at the beginning and end, replace a highlighted phrase and try a selection containing an emoji. Verify both the resulting value and caret position. Check undo behavior in the supported browsers rather than assuming every programmatic editing method participates identically in native history.

Keep the action’s label explicit and return focus only when that matches the user’s workflow. The example inserts literal text; it does not evaluate the token or parse it as markup.

Understand code units and visible characters. Synchronize programmatic and user edits.
