Trace Alternating Animations One Iteration at a Time

Distinguish normal, reverse, alternate and alternate-reverse playback, then check iteration boundaries and the final state of a finite animation.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Make the first two passes easy to observe
  2. Distinguish direction from the end-state policy
  3. Use a timeline table in the review

Animation-direction controls how each iteration traverses the keyframes. Alternate runs forward first and backward second; alternate-reverse begins backward. It does not double the declared duration of an individual iteration, although a round trip takes two iterations.

Make the first two passes easy to observe

.sample-dot {
  animation: travel 2s linear 2 alternate;
}
@keyframes travel {
  from { transform: translateX(0); }
  to { transform: translateX(120px); }
}
@media (prefers-reduced-motion: reduce) {
  .sample-dot { animation: none; }
}

Use a small visible element in a track wide enough for the movement. This finite specimen runs from 0 to 120px during the first two seconds and returns during the next two. Linear timing isolates direction from easing. The example intentionally avoids an endless attention-catching loop.

Reference: MDN animation-direction.

Distinguish direction from the end-state policy

Normal starts each pass from the first keyframe. Reverse traverses the sequence backward each time. Alternating modes switch direction on successive passes. Reversing playback also reverses the timing-function progression, so an eased return may feel different from a separately authored forward movement.

When playback finishes, fill mode determines whether an animation value remains applied. The last relevant keyframe depends on direction and iteration count. Do not assume forwards always means the 100% keyframe.

Use a timeline table in the review

For this specimen, record 0px at the start, 120px at two seconds and 0px at four seconds. Change to three iterations and check the new ending deliberately. Pause near each boundary when investigating a visible jump; also inspect delays and the underlying transform. Review the reduced-motion state separately.

See fill-mode behavior for before-and-after values and the motion preference checklist for a useful static alternative.
