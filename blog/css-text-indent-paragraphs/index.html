Indent a Paragraph’s First Line Without Padding Every Line

Use text-indent for a first-line paragraph treatment. Compare it with padding, inspect inheritance and test narrow widths before applying an editorial style.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Apply the treatment to a deliberate paragraph sequence
  2. Inspect units and inheritance
  3. Compare the real reading experience

Use text-indent when the first line should start inward while later lines return to the normal text edge. Padding moves the content edge for every line. They can look similar in a one-line paragraph, so compare them using text that wraps.

Apply the treatment to a deliberate paragraph sequence

.essay {
  max-inline-size: 65ch;
  line-height: 1.6;
}
.essay p { margin-block: 0; }
.essay p + p { text-indent: 1.25em; }

This original editorial pattern indents a paragraph only when another paragraph immediately precedes it. A paragraph after a heading is not indented by that selector. Decide whether that is the intended reading rhythm; do not apply it to form help, status messages or card descriptions just because they also use paragraph elements.

Reference: MDN text-indent.

Inspect units and inheritance

An em value scales with the text size. A percentage is relative to the containing block’s width, so the indent can change substantially as the reading column grows. Inspect the computed declaration and the containing block instead of interpreting a percentage as a share of the first word.

Text-indent is inherited. If the rule is placed high in a component tree, nested blocks may receive an unexpected indent. Keep the selector scoped and reset the value on intentionally different nested text where necessary. Negative indents can push text outside its box; they need a clear layout reason and overflow review.

Compare the real reading experience

  • Use several multiline paragraphs with different opening words.
  • Resize the text column and increase the font size.
  • Insert a heading, a quote and a list between paragraphs.
  • Review right-to-left content in its correct direction and language.

Avoid stacking a large indent, large paragraph gaps and narrow columns without evaluating the resulting rhythm. Each treatment signals a break; combining them can make short copy feel fragmented. For a hanging label or a numbered instruction, semantic lists or a small grid may express the structure better than an unusual indent.

Use the reading-width guide to set the column context, then compare indentation with paragraph spacing in the actual typeface. Capture the selector rule in the handoff so the style follows content structure rather than being manually added to selected paragraphs.
