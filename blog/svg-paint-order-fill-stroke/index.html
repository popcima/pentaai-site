Paint a Stroke Behind an SVG Fill Without Duplicating Geometry

Use paint-order to put an outline behind the fill, compare unchanged stroke geometry, and inspect small labels without confusing paint order with stacking order.

By Penta AIPublished 24 November 20261 min read

In this guide

  1. Compare two otherwise identical shapes
  2. Keep paint order separate from element order
  3. Inspect the final small-size result

Paint-order changes the order in which an element’s fill, stroke and markers are painted. Drawing the stroke first lets the fill cover its inner portion. This can keep an outlined shape or letterform clearer without maintaining duplicate SVG geometry.

Compare two otherwise identical shapes

<svg viewBox="0 0 260 120" width="360" height="170" aria-hidden="true">
  <circle cx="65" cy="60" r="35" fill="#dceaff" stroke="#1756a0" stroke-width="16"/>
  <circle cx="195" cy="60" r="35" fill="#dceaff" stroke="#1756a0" stroke-width="16"
          style="paint-order:stroke fill"/>
</svg>

The second circle paints its stroke before its fill. The fill covers the stroke’s inner half, leaving the outer part visible. The circle radius and declared stroke width are unchanged. The specimen is decorative, so it is hidden from the accessibility tree.

Reference: MDN SVG paint order stroke fill.

Keep paint order separate from element order

This property does not move an SVG element above another element like changing document order or stacking. It reorders paint operations within the affected element. If an entire icon is behind another shape, inspect their composition instead.

A stroke still extends around its path geometry. Changing which part is overpainted does not turn it into a separate outside-only border model. Check clipping at the SVG viewBox edge when a thick outer portion reaches beyond the available area.

Inspect the final small-size result

Apply the comparison to the actual icon or outlined text and reduce it to the intended display size. Check narrow gaps, counters inside letters and corners where a thick stroke can dominate. Try a different foreground/background pair rather than assuming one outline fixes every contrast problem.

For informative graphics, retain appropriate text alternatives and readable labels. Paint-order is a rendering adjustment; it does not supply a name, change the source text or establish that a small outlined label is legible.

Review stroke geometry and visible extent. Name informative SVG content.
