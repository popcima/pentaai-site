Diagnose Gaps in Text Underlines Before Replacing Them

Check text-decoration-skip-ink when underlines break around letter descenders, compare the actual font, and keep links recognizable across wrapped lines.

By Penta AIPublished 20 November 20261 min read

In this guide

  1. Compare the same text with two policies
  2. Check the font and offset together
  3. Keep the link recognizable at reading size

An underline that breaks around letters such as g, p or y may be working as intended. Text-decoration-skip-ink lets the browser interrupt decoration near glyph ink. Determine whether you are seeing intentional gaps before replacing the underline with a border.

Compare the same text with two policies

.sample-link {
  text-decoration-line: underline;
  text-decoration-thickness: .08em;
  text-underline-offset: .12em;
  text-decoration-skip-ink: auto;
}
.sample-link.continuous { text-decoration-skip-ink: none; }

Use the same linked phrase containing descenders, such as “Typography playground,” in both specimens. Auto allows interruptions around glyphs; none draws continuously through the text’s decoration path. Keep the font, size, thickness and offset identical so the policy is the only changing variable.

Reference: MDN text-decoration-skip-ink.

Check the font and offset together

The visible gap depends on the glyph outlines and underline placement. A fallback font can produce a different result from the intended web font. Compare after the actual font loads, and inspect a language-relevant sample rather than a single Latin word if the interface supports other writing systems.

A bottom border belongs to the element’s box and does not automatically behave like text decoration across wrapped lines. Replacing an underline with a border can trade one visual difference for alignment and wrapping problems.

Keep the link recognizable at reading size

Review normal-sized body text, enlarged text and a link that spans two lines. Try default, hover and keyboard-focus states. If gaps make the underline difficult to perceive, adjust thickness or offset and compare again before forcing a continuous line through descenders. Preserve sufficient contrast and an independent focus indicator.

Use the complete underline styling guide for the broader link treatment and font inspection to confirm which outlines you are actually judging.
