Read Horizontal and Vertical Corner Radii Around the Slash

Decode border-radius slash syntax, compare elliptical and circular corners, and inspect browser scaling when large radii compete for limited box space.

By Penta AIPublished 24 November 20261 min read

In this guide

  1. Compare a circular and an elliptical treatment
  2. Expand each side of the shorthand independently
  3. Test the smallest supported box

The slash in border-radius separates horizontal radii from vertical radii. It does not separate top corners from bottom corners. Understanding those two axes helps reproduce an elliptical corner without adding unexplained per-corner overrides.

Compare a circular and an elliptical treatment

.corner-sample { width: 240px; height: 120px; background: #dceaff; }
.corner-sample.circular { border-radius: 40px; }
.corner-sample.elliptical { border-radius: 60px / 20px; }

The circular specimen uses 40px in both directions at each corner. The elliptical specimen uses a 60px horizontal radius and a 20px vertical radius. Both retain the same rectangular box dimensions, making the shape difference easier to inspect.

Reference: MDN CSS border radius slash elliptical corners.

Expand each side of the shorthand independently

When four values appear before the slash, they follow top-left, top-right, bottom-right and bottom-left order for the horizontal radii. The values after the slash follow the same corner order for vertical radii. Two values without a slash instead distribute values across opposite corners; they do not define an ellipse’s two axes.

Percentages refer to the corresponding box dimension, so a shape can change as its aspect ratio changes. Large radii can also be proportionally reduced when adjacent corners would overlap. The authored number is not always the final visible arc size.

Test the smallest supported box

Reduce the specimen’s width until the horizontal corner requests compete for space, then compare the result with the larger box. Inspect long labels and different heights before turning the chosen curve into a reusable token.

Record both radii and the representative box dimensions in a handoff. If an image must follow the curve, review clipping on the media element separately; rounding the shell should not accidentally cut off focus outlines or an attached menu.
