Compare Gradient Midpoints with an Explicit Color Space

Compare sRGB and Oklab gradients with identical stops, preserve a fallback, and record the interpolation space when handing off a color treatment.

By Penta AIPublished 23 November 20262 min read

In this guide

  1. Hold the stops constant while changing the space
  2. Record the color model with the values
  3. Inspect the whole ramp under the actual content

Two gradients can share their endpoint colors and still differ between those endpoints. The interpolation color space determines the path between the stops. Specify it when the intermediate colors are part of the design, and compare the complete rendered gradient rather than only its endpoint swatches.

Hold the stops constant while changing the space

.ramp {
  min-height: 5rem;
  background: linear-gradient(90deg, #bd392f, #1557c0);
}
@supports (background: linear-gradient(90deg in oklab, red, blue)) {
  .ramp.srgb { background: linear-gradient(90deg in srgb, #bd392f, #1557c0); }
  .ramp.oklab { background: linear-gradient(90deg in oklab, #bd392f, #1557c0); }
}

Place two ramps next to each other with the srgb and oklab classes. The older-syntax declaration supplies a fallback; the support query gates the explicit comparison. Keep their widths and stops identical so the midpoint difference comes from interpolation rather than changed geometry.

Reference: MDN CSS gradient color interpolation.

Record the color model with the values

A handoff containing only two hex colors is incomplete when the middle of the gradient matters. Include angle, stop positions and interpolation space. Polar spaces can also expose a hue-path choice, which is a separate decision from this rectangular-space comparison.

Do not describe Oklab as automatically accessible or visually correct. It offers a different interpolation model; the resulting colors still need review against the content and background. A pleasing midpoint can remain unsuitable behind small text.

Inspect the whole ramp under the actual content

Compare the fallback and both enhanced ramps at the intended size. Put the real heading or control over each, and examine where its letters cross the intermediate colors. Repeat after wrapping or resizing moves the content to another part of the ramp.

When exporting a static image, verify that the export reproduces the intended color treatment. A screenshot or image-tool preset with different interpolation settings may not match the CSS even when its endpoint labels look identical.

Inspect angles and stop positions. Keep gradient text readable without its effect.
