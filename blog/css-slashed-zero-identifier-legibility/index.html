Distinguish Zero from Letter O with a Supported Font Feature

Use slashed-zero for identifiers when the font supports it, compare real glyphs and fallback behavior, and preserve the original characters when copying.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Compare the same identifier in two specimens
  2. Keep numeric features independent
  3. Test recognition and copying in context

Slashed-zero asks a supporting font to use an alternate zero glyph. It can help distinguish the digit 0 from the letter O in identifiers, but it does not replace the underlying character or manufacture a feature missing from the font.

Compare the same identifier in two specimens

.identifier { font-variant-numeric: slashed-zero; }
.identifier.baseline { font-variant-numeric: normal; }

Use a clearly labeled example string such as REVIEW-0O10 in both elements. Keep the font family, weight and size identical. Then compare the actual rendered zero and letter O. The short rule intentionally leaves font selection to the project; first confirm the loaded font provides a suitable alternate.

Reference: MDN font-variant-numeric.

Keep numeric features independent

Slashed-zero and tabular-nums solve different problems. The first changes the zero’s shape; the second requests equal-width figures for alignment. They can be combined when supported, but one does not imply the other. A monospace family can still have a zero design that is difficult to distinguish at a small size.

A CSS declaration appearing in the Styles panel does not prove the requested glyph exists in the active font. Check the rendered font and compare after loading completes. A fallback face can change the result even while the property remains present.

Test recognition and copying in context

Review mixed letters and numbers at the size used in the interface, including a narrow mobile layout. Copy the identifier into a plain-text editor and confirm the original zeros remain zeros. Do not replace 0 with a visually similar Unicode character just to imitate the slashed shape; that would change the identifier’s value.

Consider a copy control or clearer grouping for long codes, while preserving a readable selectable value. Use font inspection to verify the active face and tabular numerals when numeric column alignment is also required.
