Control Tab Stops in Displayed Code Without Rewriting It

Use tab-size with preserved whitespace, distinguish tabs from spaces, and compare copied source with the visual indentation in a code specimen.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Preserve whitespace and set the tab interval
  2. Check the rendering pipeline
  3. Keep copying and navigation useful

Tab-size changes the visual spacing of tab characters in preserved text. It does not replace tabs with spaces in the source. If a code sample’s indentation refuses to change, first inspect whether its leading characters are tabs at all.

Preserve whitespace and set the tab interval

<pre class="code-sample"><code>card {
&#9;color: blue;
}</code></pre>
<style>
.code-sample {
  white-space: pre;
  overflow: auto;
  tab-size: 4;
  font-family: monospace;
}
</style>

The numeric character reference creates one actual tab before color. The value 4 establishes tab intervals based on four space advances in the selected font. A tab advances to a tab stop, so its visible width depends on the preceding position; it is not always equivalent to inserting exactly four spaces.

Reference: MDN tab-size.

Check the rendering pipeline

A formatter, Markdown processor or syntax highlighter may expand tabs before the browser receives the text. Inspect textContent and the generated markup when changing tab-size has no effect. Normal whitespace collapsing can also prevent the intended tab layout from surviving.

Length values are possible, but a fixed pixel interval does not scale with the font the same way a number-based interval does. Choose the representation that matches the source viewer’s purpose and test it with the actual font.

Keep copying and navigation useful

Copy the specimen into a plain-text editor to see what readers actually receive. Test a line with a tab after existing characters, a line indented with spaces and an unusually long line. Ensure horizontal scrolling does not create overflow for the whole page or hide a copy button’s focus indicator.

Use whitespace rules when deciding whether lines may wrap, and the long-content guide for prose that should not behave like source code.
