Make a Single-Line Ellipsis Work Without Losing the Full Value

Combine text-overflow with an actual width constraint and overflow policy. Check flex minimum sizes and provide a reliable way to read the complete value.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Create a constrained text region
  2. Keep the complete value available
  3. Test ambiguity as well as geometry

Text-overflow ellipsis controls how clipped inline content is signaled; it does not create the overflow by itself. A working single-line treatment needs a constrained box, a no-wrap policy and hidden overflow. Diagnose those prerequisites before adding more ellipsis declarations.

Create a constrained text region

.file-row { display: flex; gap: .75rem; }
.file-row .name {
  min-width: 0;
  flex: 1 1 auto;
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
.file-row .action { flex: 0 0 auto; }

Place the row inside a container with a meaningful available width and use a long filename. Min-width zero allows the text flex item to shrink instead of insisting on its automatic content minimum. The neighboring action remains a separate box rather than being clipped with the label.

Reference: MDN text-overflow.

Keep the complete value available

The visually shortened string is not always enough to distinguish two similar files. Provide a clear details view, copy action or other accessible way to obtain the complete value. A mouse-only hover tooltip or title attribute should not be the sole recovery path.

Check whether truncation is appropriate at all. For instructions, error messages and short primary actions, wrapping is often better. A filename list may use an ellipsis for density while a confirmation screen displays the full name. Treat those as different reading tasks rather than applying one global class.

Test ambiguity as well as geometry

  • Use two filenames that share a long prefix.
  • Check narrow layouts and enlarged text.
  • Keep focus indicators outside the clipped text box.
  • Verify the complete value can be read and copied with keyboard and touch input.

For several lines of editorial preview text, review multiline clamping instead. For content that must remain visible, use long-word wrapping. The useful acceptance check is not merely “an ellipsis appears”; it is that users can still identify and act on the correct item.
