Inspect an Image’s Selected Source and Natural Size

Read currentSrc and naturalWidth alongside the rendered image box. Distinguish responsive source selection, loading success and density-corrected dimensions.

By Penta AIPublished 18 November 20261 min read

In this guide

  1. Capture a complete inspection record
  2. Avoid comparing different units as if they were identical
  3. Compare the conditions that trigger the mismatch

An image has more than one useful size: the selected resource, its intrinsic density-corrected dimensions and the box painted by CSS. Read these separately when a responsive image looks soft or unexpectedly cropped. The src attribute alone may not identify the resource the browser selected.

Capture a complete inspection record

const img = document.querySelector('.reference-image');
await img.decode();
const box = img.getBoundingClientRect();
console.table({
  selectedURL: img.currentSrc,
  naturalWidth: img.naturalWidth,
  naturalHeight: img.naturalHeight,
  renderedWidth: box.width,
  renderedHeight: box.height
});

Use this with an actual image element and handle a rejected decode promise when loading fails. Record the viewport and device pixel ratio with the values. If the image is lazy-loaded, bring it into the intended loading conditions before interpreting a zero natural size.

Reference: MDN selected image source.

Reference: MDN naturalWidth.

Avoid comparing different units as if they were identical

Natural width is expressed in CSS pixels after density correction, so it is not always the raw pixel width of the downloaded file. A 2x candidate can have twice the resource pixels while describing the same intrinsic CSS width. Inspect the resource itself when the file dimensions are the question.

CurrentSrc tells you which URL was selected; it does not prove the resource successfully loaded. Conversely, a rendered box can exist even when the image has failed because CSS or HTML dimensions reserve space. Check the network result and decoding state before blaming object-fit.

Compare the conditions that trigger the mismatch

  • Capture the selected URL at a narrow and a wide viewport.
  • Record device pixel ratio and any emulation setting.
  • Compare CSS box dimensions with object-fit and object-position.
  • Test an uncached load when investigating responsive candidate selection.

Use the srcset and sizes workflow to correct slot assumptions. Use the image fitting guide when the resource is correct but the box crops it. Keep those diagnoses separate so a layout fix does not unnecessarily increase download size.
