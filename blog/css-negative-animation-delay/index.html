Start a CSS Animation Partway Through Its Timeline

Use a negative animation delay to inspect an offset phase. Distinguish elapsed progress from faster playback and check iteration, fill and reduced-motion behavior.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Freeze a known point in the timeline
  2. Check more than the first iteration
  3. Review the actual motion contract

A negative animation delay starts the animation as though some of its active time has already elapsed. It does not increase playback speed. Use a small controlled specimen to inspect a phase offset before applying the technique to several decorative elements.

Freeze a known point in the timeline

@keyframes move-sample {
  from { transform: translateX(0); }
  to { transform: translateX(100px); }
}
.sample {
  animation: move-sample 4s linear infinite;
  animation-delay: -1s;
  animation-play-state: paused;
}

For this linear, normal-direction example, the initial frozen state is one second into a four-second iteration, or a 25px translation. Remove the paused state in a local fixture to observe the same four-second pace continuing from that offset. Keep the animation decorative and provide a reduced-motion alternative before shipping it.

Reference: MDN negative animation delay.

Check more than the first iteration

Iteration count and direction affect what an offset means. A negative delay that skips beyond a finite animation’s active duration can put it into its after phase, where fill behavior matters. An alternating direction also changes the mapping between elapsed time and the visible keyframe value.

When several animations are listed, inspect the corresponding delay and duration entries. Copying one negative value into a list without matching the intended animation can stagger the wrong effect. A later animation shorthand can also reset a delay you set earlier.

Review the actual motion contract

  • Compare zero, positive and negative delay with the same duration.
  • Inspect the initial state and the transition into the next iteration.
  • Test finite playback and the chosen fill mode.
  • Check a paused state and the reduced-motion path.

Use the fill-mode guide for before and after states and DevTools timing inspection for the running sequence. Record duration and phase offset separately in the handoff; “starts later” and “starts further through” are different requirements.
