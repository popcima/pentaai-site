Mark the Current Navigation Page with aria-current

Pair a visible active-link style with aria-current="page". Keep navigation semantics, route matching and keyboard focus separate from selected tab behavior.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Keep the current item a recognizable link
  2. Define current within each navigation set
  3. Verify the route matching rule

A navigation menu should identify the current page beyond a color change. aria-current="page" gives that relationship to assistive technology while ordinary link markup preserves navigation behavior. Use it for the page currently represented in the menu, and update it when the route changes.

Keep the current item a recognizable link

<nav aria-label="Project">
  <a href="/overview/">Overview</a>
  <a href="/files/" aria-current="page">Files</a>
  <a href="/settings/">Settings</a>
</nav>
nav a[aria-current="page"] {
  font-weight: 700;
  text-decoration: underline;
  text-underline-offset: .25em;
}

The paths are examples. A weight and underline cue makes the state visible without relying solely on color. Preserve a separate focus indicator; a link being current does not mean it currently has keyboard focus.

Reference: MDN: aria-current.

Define current within each navigation set

Usually one item in a related set is current. A page may contain separate navigation contexts, such as a main menu and breadcrumbs, each representing the same current location. Evaluate each set rather than removing every repeated current marker across the entire document.

A tab widget has its own selected-tab semantics and keyboard interaction. Do not replace aria-selected with aria-current simply because both designs use an active-looking underline. A multi-step process can use a different current value, such as step, when that is the relationship being conveyed.

Verify the route matching rule

  • Load the page directly rather than only following the menu.
  • Navigate between sibling pages and confirm the marker moves.
  • Check nested routes and trailing slashes.
  • Inspect the current-link announcement and visible focus independently.

Avoid a broad string match that marks both /files/ and /files/archive/ as separate current pages in the same set. Decide whether a parent section should be visually highlighted while the exact page is marked current, and express those as separate rules. Include direct-load and client-side navigation cases in the handoff so the marker does not become stale after a route transition.
