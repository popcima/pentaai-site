Remove an Underline at Its Source Instead of Fighting a Child

Trace text-decoration drawn by an ancestor, understand why a child’s none declaration cannot erase it, and preserve a clear link affordance when changing markup.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Use a minimal ancestor-and-child comparison
  2. Move the decoration to the intended text range
  3. Compare appearance with computed evidence

A child can have text-decoration: none and still appear underlined when the decoration is drawn by an ancestor. This is decoration propagation, not ordinary inheritance of the child’s text-decoration value. Inspect where the underline starts before increasing specificity on the child.

Use a minimal ancestor-and-child comparison

<p class="decorated">Review <span>this label</span> carefully.</p>
<style>
.decorated { text-decoration: underline; }
.decorated span { text-decoration: none; }
</style>

The span’s words remain within the ancestor’s decorated text. Looking only at the span’s computed text-decoration can therefore mislead an inspection. Toggle the declaration on decorated to identify the owner of the visible line. Keep the same markup while isolating that one change.

Reference: MDN text-decoration.

Move the decoration to the intended text range

If only certain words should have the line, apply it to those text ranges rather than to a wrapper spanning everything. Do not use stronger selectors on the child to fight a decoration drawn elsewhere. Changes to display or formatting context can alter rendering, but they can also introduce wrapping and alignment differences.

For a navigation link, removing the underline may remove a useful affordance. Decide how the entire clickable range remains recognizable instead of styling a child to look unrelated to its parent link.

Compare appearance with computed evidence

Inspect the ancestor and descendant in DevTools, noting which node owns the declaration. Add a line break by narrowing the container and check where the decoration continues. Review hover and focus states separately because another rule may introduce a second decoration.

Document the relationship in the component handoff so the next reviewer does not interpret a computed none as proof that no line can be visible. Use the resolved-style guide for evidence and the underline styling guide for a readable final treatment.
