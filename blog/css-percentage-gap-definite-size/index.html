Resolve Percentage Gaps Against the Right Container Size

Measure percentage gaps against a definite content box, then test automatic sizing and compare grid and flex behavior before choosing a spacing token.

By Penta AIPublished 23 November 20262 min read

In this guide

  1. Start with a definite inline size
  2. Isolate cyclic sizing instead of generalizing from one layout
  3. Choose a gap that communicates the spacing intent

A percentage gap refers to the corresponding dimension of the container’s content box. The difficult case is a dimension that depends on its contents: the gap and container size can depend on each other. Grid and flex layout do not resolve every cyclic percentage case the same way.

Start with a definite inline size

.gap-demo {
  display: grid;
  inline-size: 400px;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  column-gap: 10%;
}
.gap-demo > div { min-block-size: 60px; }

Two items in this horizontal-writing specimen leave a 40px column gap. The remaining 360px is shared between the tracks, making each 180px wide. Padding is outside the content-box reference in this initial example; changing box-sizing or the actual content width changes the arithmetic.

Reference: MDN CSS percentage gap sizing.

Isolate cyclic sizing instead of generalizing from one layout

Next try an automatically sized block direction with a percentage row gap and fixed-height children. In grid, a cyclic percentage gap can contribute zero during intrinsic sizing and still produce a gap during layout, allowing content to overflow the resulting box. Flex percentage gaps can resolve differently when the relevant size is indefinite.

Do not transfer a successful grid result directly to a column flex container. Keep the layout mode, gap direction and definite or indefinite dimension in the reproduction. A computed percentage string alone does not tell you the visible distance.

Choose a gap that communicates the spacing intent

Measure adjacent item rectangles after layout and compare their separation with the container’s content dimensions. Repeat with longer text, a narrow viewport and an explicit size removed. This distinguishes a percentage-resolution problem from distributed alignment adding extra space.

If the design needs a stable spacing step rather than a container-relative distance, use a length token such as 1rem. Percentage spacing should be intentional and reviewed at the smallest and largest supported container sizes.
