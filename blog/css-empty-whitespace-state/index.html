Debug an Empty-State Selector That Whitespace Prevents

Inspect text nodes when :empty fails, compare comments and hidden children, and use explicit state when visual emptiness differs from DOM structure.

By Penta AIPublished 23 November 20261 min read

In this guide

  1. Compare three small containers
  2. Define what empty means to this interface
  3. Test formatting and generated markup

An element can look empty while failing to match :empty. In current browser behavior, whitespace text nodes and child elements can prevent the match. The selector asks about DOM content, not whether a reader can see any pixels inside the box.

Compare three small containers

<div class="result" id="bare"></div>
<div class="result" id="space"> </div>
<div class="result" id="comment"><!-- placeholder --></div>
<style>
.result { min-height: 2rem; border: 1px solid; }
.result:empty { background: #e5f2eb; }
</style>

The bare and comment-only containers match; the space-containing one does not in current implementations. Inspect childNodes rather than only children, because children omits text nodes. A nested empty span also changes the structural test even if it contributes no visible text.

Reference: MDN CSS empty whitespace selector.

Define what empty means to this interface

A display:none child still exists in the DOM. Generated CSS content does not create a child node for this selector. Those differences make :empty a poor substitute for a richer application state such as “no search results after loading has finished.”

For a business state, set an explicit attribute or render a real status message from the application’s data. Keep loading, failed, filtered-out and truly absent results separate. A decorative background alone does not explain the empty state to a reader.

Test formatting and generated markup

Compare compact markup with a pretty-printed version that introduces a newline between tags. Repeat after a framework inserts an invisible wrapper or text node. Inspect the result in the browsers being supported because the selector’s specification and implementation behavior have differed around whitespace.

Do not strip meaningful spaces from user content simply to make a selector match. If formatting whitespace should be ignored by the product’s definition, calculate that state deliberately and keep the CSS selector aligned with it.

Refresh queries after DOM changes. Announce meaningful result states.
