Understand What Dense Grid Packing Does to Visual Order

Compare sparse and dense auto-placement with mixed item spans, identify backfilled holes, and check keyboard order before using dense packing for controls.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Create a visible one-cell hole
  2. Do not mistake packing for a semantic reorder
  3. Review realistic spans and content

Grid-auto-flow: dense lets a later small item fill a hole left earlier in the grid. It can improve packing while changing the visual order. The DOM and usual keyboard sequence do not automatically rearrange to follow that packed layout.

Create a visible one-cell hole

<div class="review-grid">
  <button class="wide">A</button>
  <button class="wide">B</button>
  <button>C</button>
</div>
<style>
.review-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-flow: row dense;
  gap: 8px;
}
.review-grid .wide { grid-column: span 2; }
</style>

This deliberately interactive specimen exposes the ordering issue. A occupies two cells in the first row; B needs two cells and starts in the second row. Dense placement lets C return to the remaining first-row cell. Remove dense to compare the sparse placement without changing the item widths.

Reference: MDN grid-auto-flow.

Do not mistake packing for a semantic reorder

The markup still says A, B, C. Keyboard focus through the native buttons follows that sequence, which can jump from the first row to the second and back. A timeline, ordered process or action list often needs its visual arrangement to reinforce the same sequence.

Dense packing is also not a general masonry algorithm. It fills available grid holes according to grid placement rules; it does not simply stack every item under the shortest column. Inspect the actual track and span model.

Review realistic spans and content

Test several item counts, long labels and the narrowest supported column count. Tab through every control while watching its location. Keep sparse placement when packing makes the sequence confusing, and avoid repairing the visual order with positive tabindex values.

Use the visual and keyboard order checklist to assess meaning, and implicit row sizing when the newly created rows have unexpected heights.
