Why Flexbox Shrinks Your Button—and How to Fix It

Diagnose a squeezed button in a flex row. Inspect the flex basis, minimum size and available space, then decide which item should shrink or wrap.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Give each item an explicit job
  2. Check the shrink calculation before changing width
  3. Review realistic content

A width on a flex item is not always its final width. When a row runs out of space, shrinkable items can become narrower. For a file row with a filename and an action button, give the text room to adapt while protecting the action’s readable label. If neither fits, change the arrangement rather than hiding the overflow.

Give each item an explicit job

<div class="file-row">
  <span class="file-name">homepage-navigation-review.txt</span>
  <button class="file-action" type="button">View details</button>
</div>
.file-row { display: flex; gap: 1rem; align-items: center; }
.file-name { flex: 1 1 auto; min-inline-size: 0; overflow-wrap: anywhere; }
.file-action { flex: 0 0 auto; }
@media (max-width: 28rem) {
  .file-row { flex-direction: column; align-items: stretch; }
}

This example lets the filename wrap and moves to a vertical layout at a deliberately chosen breakpoint. The button is a layout specimen; connect its action in your application. Do not copy the breakpoint without checking your actual labels, font and container width.

Check the shrink calculation before changing width

The browser distributes negative free space using each item’s shrink factor multiplied by its flex base size. Equal shrink factors therefore do not imply equal pixel reductions. Minimum-size constraints can also stop an item shrinking. In DevTools, inspect flex-grow, flex-shrink, flex-basis and the computed minimum width together.

Reference: MDN: flex-shrink.

Temporarily remove a fixed width on the row to see whether the problem comes from its parent. Then disable the button’s shrink factor. If the button recovers but the row overflows, the experiment has located the tradeoff; it has not completed the repair. Decide how the filename and row should respond at that size.

Review realistic content

  • Try a short filename, a long unbroken filename and a translated action label.
  • Zoom the page and check that the action remains visible without horizontal page scrolling.
  • Keep the focus outline clear of clipping ancestors and neighboring text.
  • Check the vertical layout with two actions if your real component supports them.

Record the flexible item, protected item and layout-change condition in the component handoff. Avoid adding flex-shrink: 0 to every child: a row full of nonshrinking items simply moves the shortage outside the container. The final design should explain where the extra content goes.
