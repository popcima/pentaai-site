overflow: hidden vs clip: Choose the Right Boundary

Compare clipping with hidden scrolling. Check focus, programmatic scrolling and formatting contexts before swapping overflow values on a component.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Compare the same clipped specimen
  2. Preserve layout behavior deliberately
  3. Audit focus and each overflow axis

hidden and clip can both conceal content outside a box, but they are not interchangeable. hidden creates a scroll container whose content can still move programmatically. clip forbids scrolling for that box. Choose based on whether the concealed content should ever be brought into view.

Compare the same clipped specimen

.preview {
  inline-size: 18rem;
  block-size: 8rem;
  border: 1px solid #9aa6b6;
}
.preview--hidden { overflow: hidden; }
.preview--clip { overflow: clip; }

Place several paragraphs inside each specimen. In a local experiment, set scrollTop on each element and inspect the result. The hidden version can change its scroll position; the clipped version does not provide that scrolling mechanism. Neither example supplies a visible scrollbar for ordinary reading.

Reference: MDN: overflow values and scroll containers.

Preserve layout behavior deliberately

hidden also establishes a new block formatting context. clip alone does not. If a layout needs that separation as well as clipping, consider display: flow-root independently. Do not assume that changing one word preserves float containment or margin behavior.

.decorative-window {
  overflow: clip;
  display: flow-root;
}

This second pattern is appropriate only when the content can safely be clipped. A paragraph required to complete a task should not be placed in a fixed-height window with no way to read the rest.

Audit focus and each overflow axis

  • Tab through any descendant controls and check whether the focused control stays visible.
  • Inspect whether sticky descendants depend on the nearest scroll container.
  • Review the computed overflow-x and overflow-y values together.
  • Test shadows, menus and focus rings crossing the boundary.

Mixing visible or clip on one axis with a scrolling value on the other can change the computed behavior. Start with the same value on both axes in a minimal specimen, then introduce the real axis requirements. In review notes, distinguish decorative clipping from a reading region that needs scrolling; a matching screenshot alone cannot establish equivalent behavior.
