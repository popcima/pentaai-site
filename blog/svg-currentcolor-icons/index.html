Use currentColor to Keep SVG Icons in Sync with Text

Make inline SVG icons inherit a component’s color through fill or stroke. Diagnose fixed colors, external image boundaries and accidental changes to multicolor artwork.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Build a stroke icon inside a labeled button
  2. Inspect the source of a stubborn color
  3. Validate the component in context

Use currentColor in an inline SVG when an icon should follow its surrounding text color. A button can then change text and icon together on hover or in another theme. First determine whether the drawing uses filled shapes, strokes or both; replacing every color indiscriminately can destroy the artwork.

Build a stroke icon inside a labeled button

<button class="download" type="button">
  <svg viewBox="0 0 24 24" width="20" height="20"
    fill="none" stroke="currentColor" stroke-width="2"
    stroke-linecap="round" stroke-linejoin="round"
    aria-hidden="true" focusable="false">
    <path d="M12 3v12m-4-4 4 4 4-4M5 17v4h14v-4" />
  </svg>
  Download sample
</button>
.download { color: #174fa0; }
.download:hover { color: #102f65; }

The path is an original simple download illustration. The visible text names the button, so the decorative SVG is hidden from assistive technology. Connect the button to the actual application action separately; the example only demonstrates the color relationship.

MDN’s SVG color reference explains that color supplies currentColor indirectly. Setting color alone does not paint a shape: fill or stroke must use the value. A filled icon might use fill="currentColor" instead of the stroke-based setup above.

Inspect the source of a stubborn color

ObservationNext check
Stroke changes but center does notLook for a separate fixed fill.
One path stays blackInspect that path’s own attributes or CSS.
Every icon ignores the button colorCheck whether a descendant explicitly sets color.
SVG in an img ignores page colorThe external image is a separate styling boundary.

An SVG loaded through an img element does not inherit the surrounding page’s color the same way inline markup does. Choose an appropriate delivery method rather than trying increasingly specific selectors that cannot reach inside the image. A CSS mask can be useful for a monochrome shape; inline SVG provides direct control over its parts.

Do not replace intentional none values with currentColor. A stroke icon often depends on an unfilled interior. Likewise, a multicolor logo may need its original palette and should not be treated as a monochrome interface symbol. Review brand artwork separately from action icons.

Validate the component in context

Check the icon and text on light and dark surfaces, in hover and focus states, and when the button is disabled. If the surrounding component uses opacity, review the combined result rather than assuming the inherited color remains readable. Compare the icon at its actual small display size so thin strokes are not judged only in an enlarged preview.

Record whether the asset is filled or stroked, its viewBox, intended size and color policy in the asset handoff. For an icon-only control, add a clear accessible name to the control. Keeping color inheritance and labeling as explicit decisions makes a reusable icon easier to maintain across themes and interaction states.
