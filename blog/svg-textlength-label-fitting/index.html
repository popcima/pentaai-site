Fit an SVG Label with an Explicit Text-Length Policy

Compare SVG textLength spacing with spacingAndGlyphs, inspect the actual font, and preserve readable labels instead of compressing unknown text blindly.

By Penta AIPublished 24 November 20261 min read

In this guide

  1. Compare the adjustment modes on one string
  2. Keep fitting separate from font selection
  3. Review the longest localized labels

SVG textLength specifies a target distance for text rendering. LengthAdjust determines whether the browser changes spacing alone or also scales glyphs to reach that distance. The second approach can visibly distort letterforms, so treat it as a deliberate label-fitting policy.

Compare the adjustment modes on one string

<svg viewBox="0 0 300 140" width="450" height="210" role="img"
     aria-label="Two illustrative fitted Review labels">
  <text x="20" y="55" font-size="32" textLength="180" lengthAdjust="spacing">Review</text>
  <text x="20" y="110" font-size="32" textLength="180" lengthAdjust="spacingAndGlyphs">Review</text>
</svg>

The string and requested length are identical. The first line adjusts spacing; the second can adjust glyph widths as well. The unspecified family uses the browser’s available font, so the exact visual change depends on that font. Use the project font for a real comparison.

Reference: MDN SVG textLength lengthAdjust.

Keep fitting separate from font selection

A condensed font face is designed with its own letterforms. Compressing an arbitrary face through length adjustment is a different operation. Do not use fitting to conceal an unexpected fallback font or a failed font request.

The text remains text rather than being rewritten into a different label. Its semantic meaning still needs an appropriate accessible representation for the overall SVG. A fitted visual does not automatically become a usable form-control label or a complete chart description.

Review the longest localized labels

Try a short label, a long label and a translated label at the actual rendered size. Inspect character collisions and unusually wide gaps, especially in the spacing-only mode. Check the final SVG after font loading rather than measuring only its authored target value.

If the required fitting becomes unreadable, allocate more space, wrap through a suitable text layout or shorten the displayed copy with a clear full-label path. Do not keep reducing or stretching text merely to preserve a fixed screenshot composition.

Choose an actual condensed font face. Measure after the relevant font-loading phase.
