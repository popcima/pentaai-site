Inspect Letter Spacing and Scale It with em

Measure tracking alongside the actual font and size. Use modest em-based spacing for a defined text role, then test wrapping, localization and user overrides.

By Penta AIPublished 14 November 20262 min read

In this guide

  1. Convert a measured relationship, not a screenshot guess
  2. Apply spacing to a defined text role
  3. Review wrapping and user-controlled spacing

Inspect letter-spacing together with font family, size, weight and case. It adds space between characters; it does not select a font or repair a font-loading failure. An em value can make intentional tracking scale with a text role’s font size, but the value still needs review with that font.

Convert a measured relationship, not a screenshot guess

.eyebrow {
  font-size: .75rem;
  font-weight: 600;
  letter-spacing: .06em;
  text-transform: uppercase;
}

If this label computes to 12px, .06em corresponds to .72px of added spacing. At 16px it corresponds to .96px. Those are arithmetic examples, not recommended values for every uppercase label. Compare the original computed declaration with the result in your own type system.

Reference: MDN letter-spacing reference.

Before copying tracking from another page, verify the font actually rendered. A fallback face can have different glyph widths and proportions. If a heading looks too loose, reducing letter-spacing may disguise a font mismatch while leaving other text roles inconsistent.

Apply spacing to a defined text role

A short uppercase eyebrow and a paragraph of body copy have different reading tasks. Keep tracking attached to a role instead of applying a large value to the entire site. Negative tracking can make letters collide at small sizes or with a heavier weight; compare real words rather than only a specimen alphabet.

Letter-spacing is inherited, so check descendants that change font size or language. A computed length inherited from a parent is not necessarily recalculated from a child’s new font size. Declare the em-based role at the element that owns the intended sizing relationship.

Review wrapping and user-controlled spacing

  • Try short and long labels, punctuation and numerals.
  • Check a loaded web font and its fallback.
  • Increase text size and spacing and look for clipping or overlapping controls.
  • Inspect localized strings rather than applying Latin tracking assumptions to every script.
  • Check that uppercase transformation has not made a meaningful label harder to read.

Use a flexible container so a spacing adjustment can wrap naturally. A fixed-width badge that fits one English word can fail once tracking or content changes. For headings, review line wrapping separately instead of tightening letters until the title fits.

In the handoff, record font, weight, size, line-height and tracking as one text style. Include a realistic long label and a narrow example. That gives the developer enough context to reproduce the visual intent without treating a single spacing number as a universal rule.
