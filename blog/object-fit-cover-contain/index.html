Object Fit Cover vs Contain: Fix Website Image Cropping

Choose cover or contain based on what an image must preserve. Define the image box, adjust the focal point and test portrait, landscape and transparent assets.

By Penta AIPublished 26 October 20263 min read

In this guide

  1. Separate the image box from its content
  2. Give contained assets an intentional surface
  3. Adjust the focal point with evidence
  4. Do not confuse cropping with delivery size
  5. Run a small asset matrix

Use object-fit: cover when an image should fill its box and cropping is acceptable. Use contain when the entire image must remain visible, even if that leaves empty space. First define the box: changing object-fit alone will not establish the layout dimensions you want.

A product photograph, logo and editorial portrait have different requirements. Decide what information must survive before selecting a crop strategy. Keeping a uniform row of thumbnails is useful only if the thumbnails still communicate their subjects.

Separate the image box from its content

.story-image {
  display: block;
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  object-position: 50% 35%;
}

The width and aspect ratio establish the rendered box in this example. Cover then scales the image content to fill it, preserving the content’s proportions while cropping excess. The position shifts which part remains visible. See the object-fit reference for the behavior of cover, contain and fill.

Asset and purposeStarting choiceReview concern
Editorial thumbnailCoverFace or subject cut off
Logo in a partner listContainEnough contrast around transparent areas
Screenshot with important edge labelsContainText remains readable
Decorative full-bleed photographCoverCrop still supports the composition

The default fill behavior can distort content when both dimensions force a different aspect ratio. If a circle in the source becomes an oval, inspect sizing and fitting before searching for a higher-resolution file. More pixels will not fix geometric stretching.

Give contained assets an intentional surface

.partner-logo {
  display: block;
  width: 100%;
  height: 7rem;
  object-fit: contain;
  padding: 1rem;
  box-sizing: border-box;
  background: #ffffff;
}

This example creates a consistent logo area without cropping the mark. The white surface is a design choice that must fit the supplied artwork and surrounding theme. Inspect transparent edges and marks with white lettering; a technically uncropped logo can still be invisible on the wrong background.

Adjust the focal point with evidence

Start with the center and compare the image at every required shape. For a portrait, move the visible region toward the face if the crop loses it. The object-position property controls alignment within the element’s box; it does not understand what the important subject is.

When one crop cannot serve both a wide hero and a small portrait card, prepare an alternate composition. A carefully chosen source variant is often better than extreme positioning. Record the focal point or alternate asset alongside the content so the decision survives a future template change.

Do not confuse cropping with delivery size

Object-fit changes presentation, not the number of bytes in the downloaded image. A small thumbnail can still fetch a very large original. Use srcset and sizes to provide suitable resolution candidates, and use cropping rules to control their appearance.

Likewise, width and height attributes can help communicate the image’s intrinsic proportions, but they do not replace a deliberate crop specification. Inspect the final computed dimensions and test loading before assuming that the intended space is reserved.

Run a small asset matrix

Test a landscape image, portrait image, square image and transparent mark in the same component. Add a missing-image case and a long caption. Check desktop and mobile crops, then confirm rounded clipping does not hide controls or meaningful text. Save the chosen fit, position, ratio and source variants as one reusable media specification.
