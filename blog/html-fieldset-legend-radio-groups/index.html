Group Radio Choices with fieldset and legend

Give related radio controls a shared question with fieldset and legend. Keep individual labels, unique IDs and native grouping behavior clear.

By Penta AIPublished 28 October 20262 min read

In this guide

  1. Write the question once
  2. Style the group without losing its question
  3. Review repeated groups and disabled states

A set of radio buttons needs both a shared question and a label for each option. fieldset groups the controls, while legend names the group. This helps a reader understand what “Compact” and “Detailed” refer to without relying only on nearby visual placement.

Write the question once

<fieldset class="report-detail">
  <legend>How much detail should the sample report show?</legend>
  <label>
    <input type="radio" name="report-detail" value="compact" checked>
    Compact summary
  </label>
  <label>
    <input type="radio" name="report-detail" value="detailed">
    Detailed notes
  </label>
</fieldset>

The wrapping labels connect each option’s wording to its input. The shared name makes the radios one mutually exclusive group. The values distinguish the submitted choices. These example controls do not produce a report until the application connects them to its own behavior.

Reference: MDN: fieldset.

Style the group without losing its question

.report-detail { border: 1px solid #b7beca; padding: 1rem; }
.report-detail legend { padding-inline: .25rem; font-weight: 600; }
.report-detail label { display: block; margin-block: .5rem; }

A legend can wrap, so check a long question at a narrow width before imposing a fixed height. If the visual design removes the fieldset border, keep the grouping understandable through spacing and a visible question. The border is optional; the relationship between question and options is not.

Review repeated groups and disabled states

A second independent radio group needs its own name. Reusing the same name across two unrelated questions can make choosing an answer in one clear the answer in the other. If you use separate label elements with for attributes, keep each input ID unique as well.

  • Tab into the group and try native arrow-key selection.
  • Click the text label, not only the radio circle.
  • Read the group with supported assistive technology.
  • Check validation messages and any disabled group state.

Disabling a fieldset affects its descendant controls, with a special exception for controls in its first legend. Avoid putting unrelated interactive controls into the legend unless that behavior is intentional. In the handoff, list the shared question, option labels, default choice and whether choosing an option immediately changes anything else on the page.
