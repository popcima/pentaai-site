Why Table Border Spacing Disappears in CSS

Compare collapsed and separate table borders. Fix missing border-spacing, doubled grid lines and misleading cell-padding changes with a focused inspection.

By Penta AIPublished 14 November 20262 min read

In this guide

  1. Choose the model that matches the table
  2. Inspect the winning edge rules
  3. Compare a small fixture before changing the full table

If border-spacing appears to do nothing, inspect border-collapse on the table. Collapsed borders share edges between adjacent cells. Separate borders keep each cell’s border independent and allow border-spacing to create gaps. Cell padding changes the space inside a cell, not the gap between cells.

Choose the model that matches the table

.data-grid {
  border-collapse: collapse;
}
.data-grid th, .data-grid td {
  border: 1px solid #b8c0cb;
  padding: .75rem;
}

.spaced-grid {
  border-collapse: separate;
  border-spacing: .5rem .75rem;
}

The first pattern suits a continuous grid. The second demonstrates different horizontal and vertical gaps. Keep the table’s real header and data-cell markup in either case. A border-model change should not turn the table into a collection of generic blocks.

Reference: MDN border-collapse reference.

Inspect the winning edge rules

Select the table and confirm its computed border model before adjusting individual cells. A reset may have established collapse globally. In the collapsed model, adjacent cell, row and table border declarations can compete at the same edge; increasing the width of one arbitrary border may not create the uniform result you expect.

For a clean separate-border grid without gaps, start with border-spacing: 0. If both adjacent cells draw a full border, their edges can appear doubled. Assign consistent sides, such as bottom and inline-end, then account for the outer boundary intentionally. Do not hide a double line by making the text or background nearly the same color.

Rounded table corners add another question: which box owns the outer edge and which box clips the content? Review that separately from cell spacing. Test actual browser painting rather than assuming a radius on each cell will round the entire table.

Compare a small fixture before changing the full table

  • Use a two-column, three-row example with visible borders.
  • Toggle collapse and separate while keeping other declarations unchanged.
  • Change spacing, then padding, and observe which areas grow.
  • Check highlighted rows and sticky cells for seams.
  • Inspect the table at a narrow width with long values.

Once the edge model is stable, apply the responsive table workflow. Gaps and borders affect the table’s width, so recheck overflow after the visual repair. Preserve readable data relationships instead of squeezing every cell to fit one screenshot.
