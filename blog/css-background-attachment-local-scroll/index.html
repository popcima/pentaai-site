Choose Whether a Background Follows the Box or Its Content

Compare local, scroll and fixed background attachment inside a scrolling panel. Test panel and page movement separately before copying a visual effect.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Build a panel with an obvious visual landmark
  2. Test the outer page independently
  3. Keep the effect optional

Inside a scrolling panel, a background can stay attached to the panel’s box or move with its content. background-attachment: scroll uses the box; local follows the scrollable contents. The names are easy to misread unless you test the panel’s scrolling separately from the whole page.

Build a panel with an obvious visual landmark

.notes-panel {
  max-height: 14rem;
  overflow: auto;
  padding: 1rem;
  background-image: linear-gradient(#dcebe3 0 4rem, white 4rem);
  background-repeat: no-repeat;
  background-attachment: local;
}

Fill the panel with enough text to scroll. The colored band provides a simple landmark without needing an external image. Scroll only the panel and observe the band, then change local to scroll and repeat. Keep the same content and panel dimensions so the attachment is the only variable.

Reference: MDN background-attachment.

Test the outer page independently

With scroll, the background stays with the element as the page moves, but does not travel with the element’s internally scrolling contents. With fixed, the background is attached to the viewport. Scroll the page while the panel remains partly visible to distinguish that viewport attachment from the other cases.

For multiple backgrounds, attachment values correspond to image layers. Inspect the full image and attachment lists together; a gradient used for a scroll cue may intentionally behave differently from a decorative texture. Also review background-origin and clipping rather than assuming attachment alone defines the painted region.

Keep the effect optional

Mobile browsers, compositing and surrounding transforms can complicate a fixed-background design. Test the actual device and component context. Do not claim a screenshot proves the scrolling behavior, and do not hide an essential boundary or instruction inside a decorative background effect.

  • Scroll the panel while holding the page position constant.
  • Scroll the page without changing the panel’s scroll position.
  • Review text contrast at every part of the background.
  • Check performance and motion comfort on target devices.

Use a plain readable surface as the fallback. If the effect creates apparent motion behind content, include it in the motion review. For misplaced painting boundaries, continue with background origin and clip instead of compensating with unexplained padding.
