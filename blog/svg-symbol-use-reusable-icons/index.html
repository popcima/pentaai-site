Reuse SVG Geometry with symbol and use

Define an SVG symbol once, instantiate it with use, preserve viewBox and currentColor behavior, and give each surrounding control a clear name.

By Penta AIPublished 23 November 20262 min read

In this guide

  1. Define one symbol and use it in a labeled action
  2. Keep references and styling predictable
  3. Test the instance, not only the definition

Symbol defines reusable SVG geometry; use creates a rendered instance that refers to it. Keep the geometry separate from each instance’s meaning. A repeated decorative icon inside labeled buttons should not introduce a second competing accessible name.

Define one symbol and use it in a labeled action

<svg width="0" height="0" aria-hidden="true" style="position:absolute">
  <symbol id="review-check-icon" viewBox="0 0 24 24">
    <path d="M5 12l4 4L19 6" fill="none" stroke="currentColor" stroke-width="2"/>
  </symbol>
</svg>
<button type="button">
  <svg width="24" height="24" aria-hidden="true" focusable="false">
    <use href="#review-check-icon"/>
  </svg>
  Mark reviewed
</button>

The symbol itself is not the visible instance. The use reference instantiates its geometry inside the button’s SVG. The visible text names the button, and the icon follows the inherited color through currentColor. This example does not implement the button’s review action.

Reference: MDN SVG symbol use icons.

Keep references and styling predictable

Use a document-unique symbol ID. A repeated component should reuse the definition rather than inject another conflicting definition with the same ID. Hard-coded fill or stroke values on the source geometry can prevent the instance from following the intended color.

Do not assume a normal descendant selector on use can style every internal referenced node like ordinary light-DOM markup. Set appropriate inherited values or design an explicit source styling contract. External sprite files add URL, origin and loading considerations beyond this same-document example.

Test the instance, not only the definition

Render the icon at two sizes and in two color contexts. Confirm the viewBox keeps the shape inside the expected area and that the button’s accessible name comes from its visible label. Check forced colors and a missing reference so the action remains understandable without the picture.

For an informative standalone graphic, provide an accessible name on the instance using a pattern tested with the supported browser and assistive technology. Reusing geometry does not automatically supply an appropriate name everywhere it appears.
