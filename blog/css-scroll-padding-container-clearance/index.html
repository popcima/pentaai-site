Reserve Scroll-Target Clearance on the Scrolling Container

Use scroll-padding-top for a shared scrollport inset, distinguish it from target scroll margins and ordinary padding, and check sticky toolbars at different sizes.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Apply the inset to the element that actually scrolls
  2. Keep container and target offsets distinct
  3. Test toolbar growth and nested scrolling

Scroll-padding-top defines an inset in a scrolling container’s preferred viewing region for targeted scrolling. It can reserve clearance for a sticky toolbar shared by many targets. It does not add ordinary layout padding above the content.

Apply the inset to the element that actually scrolls

.review-scroll {
  block-size: 240px;
  overflow: auto;
  scroll-padding-top: 56px;
}
.review-scroll .toolbar {
  position: sticky;
  top: 0;
  block-size: 40px;
  background: #fff;
}

Put the toolbar and several section headings inside review-scroll, then target a middle heading with scrollIntoView({block: "start"}). The specimen leaves 40px for the toolbar plus 16px of breathing room. A declaration on a nearby wrapper that never scrolls will not establish the same scrollport policy.

Reference: MDN scroll-padding-top.

Keep container and target offsets distinct

Scroll padding belongs to the scrolling container; scroll margin belongs to a target. They can interact, so inspect both before doubling an offset to fix a remaining overlap. Ordinary padding affects layout and scrollable content dimensions, which is a different operation.

The requested alignment is limited by the available scroll range. A target near the beginning or end may not reach the exact desired position if the container cannot scroll farther. Also avoid treating scroll padding as a universal guarantee for every browser’s focus-scrolling behavior.

Test toolbar growth and nested scrolling

Increase text size until the toolbar wraps, then recheck the inset. Use an actual size-driven value or revise the layout if a fixed 56px no longer describes the covered region. Test anchor navigation, scripted scrolling and keyboard movement separately, including a nested panel inside the main page.

Use the target-margin guide for exceptions on individual headings and scrollIntoView alignment for the requested scrolling behavior.
