Keep a Sortable Table’s Order and aria-sort in Sync

Put sort state on the active table header and sorting behavior on a native button. Reorder complete rows and verify the announced direction matches the data.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Start from a small correctly ordered table
  2. Preserve state when the implementation grows
  3. Verify action and announcement together

Aria-sort describes the current ordering of a table column or row; it does not perform sorting. Put the state on the relevant header cell, use a native button for the action and update the actual data order together with the attribute.

Start from a small correctly ordered table

<table id="samples">
  <caption>Example review samples</caption>
  <thead><tr><th scope="col" aria-sort="ascending">
    <button type="button">Name</button>
  </th><th scope="col">Owner</th></tr></thead>
  <tbody>
    <tr><td>Alpha</td><td>Team A</td></tr>
    <tr><td>Zulu</td><td>Team B</td></tr>
  </tbody>
</table>
const table = document.querySelector('#samples');
const header = table.querySelector('th[aria-sort]');
const body = table.tBodies[0];
const collator = new Intl.Collator('en', { numeric: true });
header.querySelector('button').addEventListener('click', () => {
  const descending = header.getAttribute('aria-sort') === 'ascending';
  const rows = [...body.rows].sort((a, b) =>
    collator.compare(a.cells[0].textContent, b.cells[0].textContent)
    * (descending ? -1 : 1));
  body.append(...rows);
  header.setAttribute('aria-sort', descending ? 'descending' : 'ascending');
});

This fixture sorts the complete rows, keeping each owner attached to the correct name. It is intentionally a small client-side table, not a pagination or server-query implementation.

Reference: MDN aria-sort.

Preserve state when the implementation grows

When another column becomes the sort key, remove aria-sort from the previously sorted header and set it on the new one. Use a direction indicator that is not color alone. Keep focus on the initiating button instead of replacing the entire header unnecessarily.

For remote data, represent the completed ordering truthfully. Do not announce that rows are sorted before the requested result is applied. Define how empty values, numbers and locale-sensitive names compare; a lexical comparison is not appropriate for every column.

Verify action and announcement together

  • Activate the header with keyboard and pointer.
  • Compare first and last rows after each direction change.
  • Check header associations and focus after updates.
  • Review the table with supported screen-reader combinations.

Reference: W3C sortable-table example and testing guidance.
