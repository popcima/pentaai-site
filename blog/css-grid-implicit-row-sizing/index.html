Size the Extra Rows Created by CSS Grid

Use grid-auto-rows for tracks created beyond the explicit grid. Test added items, long content and placement rules without forcing every row to a fixed height.

By Penta AIPublished 19 November 20261 min read

In this guide

  1. Add more items than the template describes
  2. Inspect placement before changing height
  3. Review growth and empty space

A grid can create additional rows when content exceeds the explicitly defined tracks. Grid-auto-rows controls the sizing of those implicit rows. If the first row looks right but later rows behave differently, inspect which tracks came from the template and which were created automatically.

Add more items than the template describes

.sample-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));
  grid-template-rows: 6rem;
  grid-auto-rows: minmax(6rem, auto);
  gap: 1rem;
}

Use six cards in this original fixture. The template explicitly sizes the first row; the remaining rows use the automatic track rule. A longer card in a later row can make that row grow. The fixed first row is intentional here to expose the distinction, not a recommendation for unknown production content.

Reference: MDN implicit row sizing.

Inspect placement before changing height

An item placed beyond the explicit grid can create implicit tracks even when the number of items is small. Inspect grid-row, grid-column and named-area assignments on the item that seems to create a gap. A mistaken placement cannot always be repaired by shrinking auto rows.

Grid-auto-flow controls auto-placement, not track height. Dense packing can fill earlier holes, but it can also produce a visual sequence that differs from DOM order. Do not enable dense solely to make a dashboard look compact without checking reading and keyboard order.

Reference: MDN grid auto-placement.

Review growth and empty space

  • Add one item at a time and inspect the created tracks.
  • Put the longest content in an implicit row.
  • Remove any fixed container height during diagnosis.
  • Check spanning items and explicit placement declarations.

If all rows are content-driven, consider omitting the fixed template row and using a consistent automatic policy. If cards need alignment with a parent’s shared tracks, review subgrid instead. Record which rows are explicit, which can grow and whether a change in item count should create a new row.
