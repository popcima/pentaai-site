Keep Padding and Backgrounds on Wrapped Inline Labels

Compare slice and clone for a highlighted phrase that wraps across lines. Review box-decoration-break fallbacks, line spacing and real text selection.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Keep the phrase inline
  2. Compare the two fragment models
  3. Check wrapping, spacing and selection together

A highlighted inline phrase can break into several line fragments. With box-decoration-break: clone, each fragment gets its own decoration instead of looking like a slice through one continuous box. This is useful for a marker-style background behind a heading phrase that must wrap naturally.

Keep the phrase inline

.heading {
  max-width: 18ch;
  line-height: 1.5;
}
.heading > .highlight {
  padding: .05em .25em;
  border-radius: .2em;
  background: #d9f2e5;
  color: #163327;
  -webkit-box-decoration-break: clone;
  box-decoration-break: clone;
}

Put ordinary text inside a span with the highlight class, and keep that span inline. Turning it into inline-block creates one atomic inline box, which changes the wrapping problem rather than solving the decoration of fragments. Use a phrase long enough to wrap into two or three lines at the test width.

Reference: MDN box-decoration-break.

Compare the two fragment models

Temporarily set the property to slice. Inspect the beginning and end of each line: cloned decorations can repeat padding, border treatment and background painting for each fragment. The effect is especially clear with rounded ends. Choose the behavior that matches the design rather than treating either value as universally correct.

Support varies across browsers and fragmentation contexts, so review the browsers you ship to. The prefixed declaration provides a compatibility path in engines that require it for this treatment. The text must stay readable when the decorative enhancement is ignored; do not encode necessary state solely through a perfect capsule shape.

Check wrapping, spacing and selection together

  • Resize until a single word moves between lines.
  • Increase font size and verify adjacent highlights do not collide.
  • Select and copy the phrase to confirm it remains real text.
  • Check the foreground against the actual highlight color.

Vertical padding on an inline element can paint beyond the line’s normal metrics. Give the heading enough line height and inspect collisions instead of adding a fixed height to contain them. Keep the full phrase available; replacing it with an image makes responsive wrapping and text selection harder.
