Use ch Units for a Readable Text Measure

Set a flexible reading width with ch while understanding what the unit measures. Review real text, font changes and padding instead of assuming an exact character count.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Constrain the measure without fixing the viewport
  2. Compare representative paragraphs
  3. Check the container in its actual context

A ch-based maximum can make a reading column follow its typography more naturally than a fixed pixel width. However, 60ch does not mean every line will contain exactly sixty characters. The unit is based on the font’s zero glyph, and proportional letters have different widths.

Constrain the measure without fixing the viewport

.reading-column {
  box-sizing: border-box;
  inline-size: 100%;
  max-inline-size: 64ch;
  margin-inline: auto;
  padding-inline: 1rem;
}

This is a starting specimen, not a universal reading-width target. Border-box includes the horizontal padding inside the maximum, so the actual text area is narrower than 64ch. Decide whether your design token describes the outer container or the content measure.

Reference: MDN: font-relative length units.

Compare representative paragraphs

Use one paragraph of ordinary prose, one with technical terms and one containing links or inline code. Measure how comfortably the eye returns to the next line. Compare the same samples with the final web font and its fallback; changing the zero glyph’s width changes the unit’s physical size.

A monospace sample may look closer to an exact character count, but spaces, punctuation, writing direction and the chosen content still deserve review. Do not infer the measure of an entire design system from a single short sentence.

Check the container in its actual context

  • Place the column beside a sidebar as well as on its own.
  • Increase browser text size and inspect surrounding controls.
  • Test long headings independently from the paragraph measure.
  • Review the narrowest supported viewport for excess side padding.

If the layout uses a maximum page width as well, identify which constraint wins at each breakpoint. A small content column inside a large page shell can be deliberate. Keep the shell width and reading measure as different roles in the handoff. That allows a future font change to be reviewed as a typography decision without accidentally redefining the entire page grid.
