Use an Outline Without Changing the Element’s Layout Size

Compare outlines and borders when a focus or selection treatment shifts nearby content. Inspect clipping and contrast without hiding the focus indicator.

By Penta AIPublished 17 November 20262 min read

In this guide

  1. Create a state that keeps its dimensions
  2. Choose where the state should be drawn
  3. Verify both the visual and keyboard states

A border participates in the CSS box model. An outline is painted around the element without reserving layout space. When adding a state indicator makes nearby content jump, compare those mechanisms before compensating with negative margins.

Create a state that keeps its dimensions

.sample-action {
  padding: .65rem 1rem;
  border: 1px solid #66756c;
  border-radius: .5rem;
  background: white;
  color: #183126;
}
.sample-action:focus-visible {
  outline: 3px solid #174fa0;
  outline-offset: 3px;
}

Measure the button before and after keyboard focus. Its border remains the same width; the outline adds a visible ring without increasing the layout box. These colors and dimensions are a specimen to test against your surfaces, not a completed accessibility assessment.

Reference: MDN outline property.

Choose where the state should be drawn

A selection border may be part of a component’s design even when focus uses an outline. Reserve its maximum thickness in the base state, then change color, if the border should not change size. With border-box sizing and a fixed width, thicker borders can reduce the content area instead of enlarging the outside box; text can still reflow.

Outline-offset controls the space between the outline and the border edge. Positive offsets can collide with neighboring controls or be clipped by an ancestor. Inspect the painted result inside scroll panels, rounded containers and dialogs. An unchanged bounding box does not prove the indicator is visible.

Verify both the visual and keyboard states

  • Tab into and out of the component without forcing pseudo-classes.
  • Compare box dimensions and nearby text wrapping.
  • Check every adjacent background and selected state.
  • Review forced-colors mode and clipping ancestors.

Do not remove the browser outline unless an effective focus treatment replaces it. A box-shadow can be decorative, but its behavior under forced colors differs from an outline or border. Use the forced-colors review to evaluate the actual result. Record focus and selection independently in the component state inventory so a selected item does not accidentally lose its keyboard indicator.
