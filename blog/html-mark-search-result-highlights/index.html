Highlight Search Matches with Meaningful HTML mark

Use mark for query-relevant text, retain readable highlighted colors, and keep result context available when assistive technology does not announce the marking.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Keep the query and result context visible
  2. Distinguish relevance from importance
  3. Test multiple and missing matches

Mark identifies text that is relevant to the reader’s current activity, such as the words matching a search query. It is a better semantic fit for search-result emphasis than using strong simply because the design calls for a colored background.

Keep the query and result context visible

<p>Results for “spacing”</p>
<p>Review the <mark>spacing</mark> between a label and its control.</p>
<style>
mark { background: #fff1a6; color: #242014; }
</style>

This is a static specimen showing the resulting markup, not a search implementation. The surrounding sentence still makes sense without the highlight. The query text above the results explains why the word has been marked; the highlight does not have to carry that explanation alone.

Reference: MDN mark.

Distinguish relevance from importance

Strong expresses importance; mark expresses contextual relevance. A query match is not automatically the most important instruction in the document. Likewise, syntax highlighting in a code block usually needs styling spans rather than labeling every colored token with mark.

If your application builds highlights from user input, construct text nodes and mark elements deliberately. Do not insert a raw query as HTML. Preserve the original text and link boundaries when a match crosses punctuation or appears inside an existing anchor.

Test multiple and missing matches

Review no matches, one match and several adjacent matches. Check the highlighted foreground/background pair in every supported theme. Read the result using assistive technology: marking is not consistently announced by default, so the result title, query context and any count should remain useful without that cue.

For dynamic searches, announce a concise result count rather than flooding a live region with every highlighted word. Use the status-message guide and the contrast checklist to review the final result presentation.
