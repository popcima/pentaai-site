Use CSS Hyphenation with the Correct Content Language

Improve narrow text columns with hyphens and accurate lang attributes. Check dictionary availability, editorial exceptions and long identifiers separately.

By Penta AIPublished 30 October 20261 min read

In this guide

  1. Apply a language-aware prose rule
  2. Separate prose from exact identifiers
  3. Compare actual reading conditions

Automatic hyphenation can help ordinary prose fit a narrow column without treating every word like a machine-generated string. The browser needs the text’s language to choose appropriate hyphenation rules. Start with accurate language markup, then review the result using real editorial copy.

Apply a language-aware prose rule

<article lang="en-US" class="narrow-notes">
  <p>Documentation should remain readable in a narrow reference panel.</p>
</article>
.narrow-notes {
  max-inline-size: 30ch;
  hyphens: auto;
}

The width is an illustrative test condition. Automatic break opportunities depend on the browser’s language resources and implementation, so the same paragraph may wrap differently on another system. A correct lang attribute also helps other language-sensitive features; do not choose it merely to force a preferred visual break.

Reference: MDN: hyphens.

Separate prose from exact identifiers

A URL, order identifier or code token has different reading requirements from an ordinary word. Hyphenation is not a universal overflow repair for those values. Use a deliberate wrapping policy for identifiers, and verify that copying the value preserves its original content.

.narrow-notes code { hyphens: none; }

For an exceptional editorial word, a soft hyphen can mark a preferred discretionary break. Use that sparingly: a document full of manually inserted opportunities becomes hard to maintain when wording or fonts change. Never rewrite the spelling simply to improve one screenshot.

Compare actual reading conditions

  • Test the final web font and its fallback.
  • Resize the text column across the intended range.
  • Review proper names and specialist vocabulary with an editor.
  • Check mixed-language passages using their own language attributes.

A narrow column may need a wider layout or different typography rather than increasingly aggressive breaks. Inspect repeated hyphenated endings across several consecutive lines and whether the words remain easy to scan. In the design handoff, state the content language, where automatic hyphenation is allowed, and which content types are exempt. Avoid promising identical line endings across browsers.
