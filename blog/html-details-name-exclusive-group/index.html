Group Native Disclosures So Only One Opens at a Time

Use the details name attribute for exclusive disclosure groups, keep group names scoped to the intended set, and test whether exclusivity helps readers compare content.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Give the intended pair one group name
  2. Avoid accidental groups across repeated components
  3. Test the native control before adding scripting

Details elements with the same name can form an exclusive group: opening one closes another open member. Use this native behavior when readers should view one section at a time. Leave disclosures independent when comparing several sections side by side is more useful.

Give the intended pair one group name

<details name="export-help">
  <summary>Image export</summary>
  <p>Choose dimensions appropriate to the intended display.</p>
</details>
<details name="export-help">
  <summary>Token export</summary>
  <p>Keep token names and units consistent with the receiving project.</p>
</details>

The shared name supplies the grouping behavior in supporting browsers; the summary remains the native control. Opening either disclosure should close the other, and closing the active one can leave both closed. This is not a requirement that exactly one panel must always remain open.

Reference: MDN details.

Avoid accidental groups across repeated components

Members do not need to sit next to each other to share a name. Reusing export-help in several independent widgets can connect sections that were meant to operate separately. Generate distinct group names for unrelated component instances.

Do not set multiple open attributes and rely on all panels starting expanded within the exclusive group. Also remember that open="false" still means the Boolean open attribute is present; remove it to close the element.

Test the native control before adding scripting

Open each summary with the pointer and keyboard, then test a repeated widget elsewhere on the page. Check that content remains usable where grouping support differs, even if several sections can stay open. Avoid layering a custom click handler that fights the browser’s own state changes.

Review whether automatically closing earlier content interrupts a comparison task. Use basic disclosure guidance for the native pattern, or the custom accordion guide when requirements genuinely need a different implementation.
