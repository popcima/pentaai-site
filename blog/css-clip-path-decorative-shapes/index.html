Use clip-path for Decorative Shapes Without Clipping Controls

Create a simple polygon crop with clip-path. Separate artwork from interactive content and check responsive geometry, layout space and focus visibility.

By Penta AIPublished 28 October 20262 min read

In this guide

  1. Keep the decoration separate
  2. Distinguish paint from layout
  3. Review what crosses the boundary

clip-path can crop the visible part of a decorative element into a custom shape. Use it on the artwork layer when the text and controls should remain ordinary rectangular content. Clipping an entire card just to angle its background can cut off focus indicators or useful content near the edge.

Keep the decoration separate

<article class="angled-card">
  <div class="angled-art" aria-hidden="true"></div>
  <div class="card-content">
    <h2>Layout reference</h2>
    <p>Review spacing and alignment.</p>
  </div>
</article>
.angled-card { position: relative; isolation: isolate; }
.angled-art {
  position: absolute;
  inset: 0;
  z-index: -1;
  background: #e7f0ff;
  clip-path: polygon(0 0, 100% 0, 94% 100%, 0 100%);
}
.card-content { padding: 1.5rem 2.5rem 1.5rem 1.5rem; }

This original polygon trims the lower-right edge of the background. The extra right padding gives the text clearance from that angled area. The decorative layer is hidden from assistive technology; meaningful text remains in the content layer.

Reference: MDN: clip-path.

Distinguish paint from layout

Clipping changes the visible region, but the element still participates in layout using its underlying box. Do not expect neighboring text to automatically flow around the polygon. If text wrapping around a shape is the requirement, investigate the appropriate layout mechanism separately.

Percentage coordinates scale with the reference box. A shape that looks subtle on a wide desktop card can appear more aggressive on a narrow, tall card. Compare the actual component proportions before choosing the final polygon points.

Review what crosses the boundary

  • Try the longest heading and enlarged text.
  • Check any future link or button near the angled edge.
  • Inspect shadows and focus outlines for unwanted clipping.
  • Disable the decoration and confirm that the content still makes sense.

Keep the unenhanced rectangular surface acceptable in browsers where the chosen clipping syntax is unavailable. Avoid encoding state or required information only in the shape. For handoff, include the polygon, the intended content-safe area and two representative component sizes, rather than only the largest visual mockup.
