Give an Informative Inline SVG a Reliable Name

Name an informative inline SVG with title and aria-labelledby, avoid duplicate IDs in repeated components, and treat decorative icons differently.

By Penta AIPublished 21 November 20261 min read

In this guide

  1. Name one self-contained graphic
  2. Choose the naming owner deliberately
  3. Check repeated instances in the accessibility tree

An informative inline SVG needs a name that communicates its purpose. A title element can supply a short description, and an explicit aria-labelledby relationship makes the intended naming source clear. Decorative icons beside an already clear label usually need a different treatment.

Name one self-contained graphic

<svg viewBox="0 0 80 40" role="img" aria-labelledby="layout-comparison-title">
  <title id="layout-comparison-title">Two equal columns with a central gutter</title>
  <rect x="2" y="2" width="34" height="36" fill="#8bb7ee" />
  <rect x="44" y="2" width="34" height="36" fill="#8bb7ee" />
</svg>

The name explains the meaningful geometry rather than saying only “image.” Title appears first inside the SVG. The graphic is intentionally simple enough for its short name; a complex chart would also need an accessible explanation of the important data and relationships.

Reference: MDN title.

Choose the naming owner deliberately

If this SVG sits inside a button whose visible text already names the action, the button may not need a second graphic name. Hide a purely decorative icon from assistive technology in that case. Avoid simultaneously adding conflicting labels to the SVG, its wrapper and the button.

An SVG loaded through img belongs to a different embedding pattern: provide the image alternative on img rather than assuming this inline relationship can be copied unchanged. Keep the graphic’s role in the surrounding interface clear before selecting markup.

Check repeated instances in the accessibility tree

Generate unique title IDs when rendering several instances. Duplicate IDs can make a reference point to another graphic’s title. Inspect the computed role and name, then verify the reading order and whether the name adds useful information. Test with the actual browser and assistive technology rather than relying on a hover tooltip.

Use name versus description relationships to separate short identification from supporting detail, and decorative icon styling when visible text already provides the action name.
