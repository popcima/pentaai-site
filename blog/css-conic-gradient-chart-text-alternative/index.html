Pair a Conic Gradient Chart with Its Actual Values

Use conic-gradient for an illustrative proportion graphic, calculate stops from the data, and keep labels and values available outside the CSS background.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Build a clearly labeled example dataset
  2. Keep the graphic and text from drifting apart
  3. Review without the circular graphic

A conic gradient can draw proportion segments around a center, but a CSS background does not expose the underlying data as readable content. Keep the values and labels in HTML, and treat the colored shape as a supporting view of the same information.

Build a clearly labeled example dataset

<figure>
  <div class="split" aria-hidden="true"></div>
  <figcaption>Illustrative review allocation</figcaption>
</figure>
<ul><li>Layout: 50%</li><li>Typography: 30%</li><li>Color: 20%</li></ul>
<style>
.split {
  width: 10rem; aspect-ratio: 1; border-radius: 50%;
  background: conic-gradient(#174f99 0 50%, #78b99a 50% 80%, #e4be65 80% 100%);
}
</style>

The values are an invented arithmetic specimen, not measurements of a Penta AI review. The cumulative stops are 50%, 80% and 100%. Repeating a boundary at the next color creates a hard transition rather than a blended region between categories.

Reference: MDN conic-gradient.

Keep the graphic and text from drifting apart

For real data, derive both the text and cumulative stops from the same validated values. Define what should happen with zero totals, missing categories or rounding that does not sum neatly to 100. Do not silently alter a number just to make the final segment look tidy.

Color alone should not be the only way to identify a category. A nearby text list makes exact values available without visual angle estimation. Consider a labeled bar chart or table when comparison is easier in that form.

Review without the circular graphic

Disable background images and read the remaining content. Confirm the title identifies what the percentages describe and the values remain complete. Check that the visible palette is distinguishable on the intended surface, then inspect a narrow layout and enlarged text.

Use the figure-caption guide for the relationship between visual and explanation, and the contrast review for labels and any meaningful graphical boundaries.
