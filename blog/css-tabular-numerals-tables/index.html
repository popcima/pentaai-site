Align Numeric Columns with CSS Tabular Numerals

Use tabular-nums for stable number columns and counters. Check font support, decimal formatting and alignment without changing the rest of your typography.

By Penta AIPublished 27 October 20262 min read

In this guide

  1. Apply the feature to the numeric cells
  2. Separate digit width from number formatting
  3. Check dynamic and fallback states

When digits shift inside a counter or look uneven in a numeric column, try tabular numerals in a font that supports them. The digits receive equal advance widths, while surrounding text can keep the site’s normal proportional typeface. This is different from switching the entire interface to a monospace font.

Apply the feature to the numeric cells

<table class="sample-totals">
  <caption>Illustrative file totals</caption>
  <thead><tr><th scope="col">Group</th><th scope="col">Files</th></tr></thead>
  <tbody>
    <tr><th scope="row">Icons</th><td class="number">111</td></tr>
    <tr><th scope="row">Images</th><td class="number">888</td></tr>
  </tbody>
</table>
.number {
  font-variant-numeric: lining-nums tabular-nums;
  text-align: end;
}

The sample values are deliberately different digit shapes. Compare their widths with the feature enabled and disabled. The chosen font must contain the relevant glyph variants; a CSS declaration cannot create a missing OpenType feature.

Reference: MDN: font-variant-numeric.

Separate digit width from number formatting

Tabular digits do not align decimal points in arbitrarily formatted strings. Values such as 9.5 and 12.50 still have different numbers of decimal places. Decide on a consistent display precision when the data allows it, and choose an alignment that suits the comparison. Do not add misleading trailing precision to measurements merely to make the table look tidy.

Currency symbols, minus signs and separators can have their own widths. Test the full formatted value, including negative numbers and the longest expected amount. A right-aligned column can help scanning, but it does not fix an unclear unit or an inconsistent formatting policy.

Check dynamic and fallback states

For a countdown or status counter, compare repeated transitions such as 11 to 88. If the number gains another digit, the overall string still grows; reserve an appropriate width only when the range is known. Avoid clipping a larger value just because the original mockup contained two digits.

  • Inspect the rendered font, including any fallback used before loading completes.
  • Compare ordinary digits, tabular digits and the actual production weight.
  • Check zoom and the narrow table layout.
  • Keep column headers and units associated with their values.

Document the feature on the numeric text style, not as a global rule for every paragraph. Proportional numerals may remain a better fit for running prose. The goal is stable comparison where it helps the reader, without flattening the typography of the whole page.
