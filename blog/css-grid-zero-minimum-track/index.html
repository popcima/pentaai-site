Shrink a Grid Track Without Hiding Its Overflowing Content

Compare 1fr with minmax(0, 1fr), separate track sizing from content overflow, and choose wrapping or local scrolling for the item inside the track.

By Penta AIPublished 22 November 20261 min read

In this guide

  1. Give the content its own overflow policy
  2. Separate the track from the grid item
  3. Measure both the grid and the code panel

A 1fr track can retain an automatic minimum influenced by its contents. Minmax(0, 1fr) gives the track an explicit zero minimum so it can fit the available space. That changes track sizing; it does not make long text or code fit inside by itself.

Give the content its own overflow policy

.inspector {
  display: grid;
  grid-template-columns: 12rem minmax(0, 1fr);
  gap: 1rem;
}
.inspector pre { min-inline-size: 0; overflow: auto; }
@media (max-width: 40rem) {
  .inspector { grid-template-columns: minmax(0, 1fr); }
}

Place navigation in the first column and a section containing a long preformatted code block in the second. Compare the flexible track with a plain 1fr while keeping the same code. Local scrolling preserves source lines; ordinary prose may instead need wrapping. The narrow-screen rule removes the fixed sidebar rather than pretending the desktop arrangement always fits.

Reference: MDN minmax.

Separate the track from the grid item

Track minimums and an item’s minimum size are related but distinct inspection points. Min-inline-size: 0 on a relevant item can allow that item to shrink, while minmax changes the grid track’s lower bound. Inspect both when a nested component still overflows after changing the parent grid.

Overflow: hidden on the entire page can conceal the symptom while cutting off content or focus indicators. Prefer a deliberate content policy at the specific element that needs it.

Measure both the grid and the code panel

Compare document width with viewport width, then inspect the code panel’s scrollWidth and clientWidth. A scrollable code block can be wider internally while the overall page remains within the viewport. Test a long URL, an image and a focused control as separate cases; their appropriate overflow behavior can differ.

Use the overflow investigation to locate the offender and the long-word guide for content that should wrap instead of scroll.
