Observe Component Size Changes with ResizeObserver

Measure a component when its own layout changes, not only when the window resizes. Choose a box, clean up observers and avoid resize feedback loops.

By Penta AIPublished 18 November 20262 min read

In this guide

  1. Observe the relevant component box
  2. Avoid measuring one box and fixing another
  3. Test component changes directly

ResizeObserver reports element-size changes even when the browser window stays the same size. That makes it useful for a preview panel affected by a sidebar or content update. Choose the box you need to observe before comparing the result with another measurement API.

Observe the relevant component box

const panel = document.querySelector('.preview-panel');
const observer = new ResizeObserver(entries => {
  for (const entry of entries) {
    const size = entry.borderBoxSize[0];
    console.log({
      inlineSize: size.inlineSize,
      blockSize: size.blockSize
    });
  }
});
observer.observe(panel, { box: 'border-box' });
// When this component is removed:
// observer.disconnect();

This example assumes a modern implementation with borderBoxSize support and a simple unfragmented box. Add a deliberate compatibility path if your support policy needs one. The logical inline and block dimensions follow writing mode; they are not universally interchangeable with physical width and height.

Reference: MDN ResizeObserver.

Avoid measuring one box and fixing another

A content-box measurement excludes padding and borders. A border-box observation includes them. A transformed visual rectangle from getBoundingClientRect answers another question again. Write down which size drives the behavior so an apparent disagreement does not lead to extra compensating pixels.

If the observer callback changes the observed element’s size, it can cause further observations and a feedback loop. Compare the intended value before writing it, separate the measurement from unrelated layout work, and investigate loop warnings rather than hiding them. Deferring work alone does not make a logically circular update correct.

Test component changes directly

  • Open and close a neighboring sidebar without resizing the window.
  • Change content length and inspect wrapping.
  • Add padding and compare the chosen box measurements.
  • Remove the component and confirm observer cleanup.

Use CSS container queries when the goal is purely responsive styling of a component. Reach for observation when JavaScript actually needs the dimensions, such as coordinating a rendering surface. The container-query guide provides the CSS alternative, while the measurement comparison helps separate layout dimensions from transformed visual bounds.
