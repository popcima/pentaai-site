Align Inline Icons with Text Using vertical-align

Diagnose baseline gaps and icon positioning in a text line. Choose vertical-align for inline boxes and flex alignment for separate layout items.

By Penta AIPublished 14 November 20262 min read

In this guide

  1. Inspect the baseline and the icon’s own box
  2. Use a layout model for a separate icon-label pair
  3. Review beyond one font size

Use vertical-align to adjust an inline or inline-block icon within a line of text. It does not vertically center a normal block inside its parent. Before changing the value, confirm whether the icon participates in an inline line box, a table cell or a flex layout.

Inspect the baseline and the icon’s own box

.inline-icon {
  display: inline-block;
  width: 1em;
  height: 1em;
  vertical-align: -0.125em;
}

The negative offset is an illustrative optical adjustment, not a universal icon token. Test it with the font and icon you actually use. An inline image normally participates in baseline alignment, which can leave room below it for text descenders. That space is not necessarily a margin or unwanted padding.

Reference: MDN vertical-align reference.

The middle keyword aligns an inline box relative to the parent’s baseline and x-height; it does not promise that the artwork will look centered against every capital letter. Extra whitespace inside an SVG viewBox can also make a correctly aligned box look wrong. Inspect the SVG coordinate bounds before adding larger offsets.

Use a layout model for a separate icon-label pair

.icon-label {
  display: inline-flex;
  align-items: center;
  gap: .4em;
}
.icon-label svg {
  width: 1em;
  height: 1em;
  flex: none;
}

This alternative centers separate flex items. It is suitable for a compact control whose icon and label should move together, but it behaves differently from an icon embedded inside a wrapping sentence. Choose the relationship first; do not combine alignment properties until something happens to look right.

For a multi-line label, decide whether the icon should align to the first line or the whole text block. Centering beside three lines may be intentional for a card action and confusing for a list bullet. Include the long-label case in the component example.

Review beyond one font size

  • Compare lowercase text, capitals and letters with descenders.
  • Test the fallback font before the web font loads.
  • Inspect at normal and enlarged text sizes.
  • Try a two-line label and a right-to-left context.
  • Check that a decorative icon is hidden from assistive technology when the text already names the action.

Save the chosen alignment with the font, line-height and icon dimensions. An offset without that context is easy to misuse when another component adopts the same icon at a different size.
